# r1.54.13 - Web

Date: 2026-06-24
Component: Web
Status: deployed

## Summary
외부에서 공유한 공연 링크를 Android 앱에서 열면 브라우저를 거치지 않고 앱이 바로 열리도록 앱 링크 검증을 추가했습니다.

## Changes
- 메신저나 SNS 등 외부에서 공유받은 공연 링크를 Android 기기에서 누르면 앱이 곧바로 열리도록 했습니다.
- 브라우저를 한 번 거치는 단계를 줄여 공유 링크로 공연 화면까지 더 빠르게 이동할 수 있습니다.
- 앱이 해당 링크를 정식으로 처리하도록 앱 링크 검증을 추가했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
