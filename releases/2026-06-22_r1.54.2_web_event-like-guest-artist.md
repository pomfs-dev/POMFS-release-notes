Date: 2026-06-22
Component: Web
Status: deployed

## Summary
이벤트 상세에서 좋아요 상태가 유지되도록 수정하고 게스트 아티스트 표시 동작을 개선했습니다.

## Changes
- 이벤트 상세에서 좋아요를 눌렀을 때 상태가 풀리지 않고 그대로 유지되도록 수정했습니다.
- 게스트 아티스트가 이벤트 상세에서 올바르게 표시되도록 동작을 다듬었습니다.
- 이벤트 화면을 닫고 다시 열어도 좋아요와 아티스트 정보가 일관되게 보이도록 개선했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
