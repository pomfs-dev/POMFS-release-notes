# r1.55.29 - Web

Date: 2026-07-12
Component: Web
Status: deployed

## Summary
운영 관리자가 앱의 테마 색상을 직접 편집할 수 있는 관리 도구를 추가했습니다(현재 기본 색상은 그대로이며, 관리자가 값을 저장하기 전까지 사용자 화면은 변하지 않습니다).

## Changes
- 관리자 패널에 테마 색상을 편집할 수 있는 탭을 추가했습니다.
- 저장한 색상 값이 없을 때는 기존 기본 색상이 그대로 유지되어, 별도 설정 전까지 사용자 화면은 변화가 없습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
