# r1.56.104 - Web

Date: 2026-09-15
Component: Web
Status: deployed

## Summary
나만의 음악 취향과 공연 관람 기록을 담은 리스너 프로필 카드가 새로 생겼습니다.

## Changes
- 프로필에 커버 사진과 프로필 사진을 각각 설정할 수 있습니다.
- 참석한 공연 목록을 자동으로 모아 보여주고, 직접 추가하거나 삭제할 수도 있습니다.
- 좋아하는 음악 취향과 다음에 갈 공연 정보를 프로필에 표시합니다.
- 나만의 프로필 주소로 프로필을 다른 사람과 공유할 수 있으며, 참석 공연 수 등 일부 정보는 기본적으로 비공개로 보호됩니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
