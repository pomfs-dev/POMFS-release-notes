# r1.55.39 - Web

Date: 2026-07-16
Component: Web
Status: deployed

## Summary
공연장 이벤트 게스트리스트 오표시와 리뷰 제출 결과 안내를 바로잡고, 오류 상황에서의 안내를 전반적으로 개선했습니다.

## Changes
- 공연장 이벤트에서 게스트리스트가 잘못 표시되던 문제를 수정했습니다.
- 공연장 리뷰 제출이 실패했는데도 성공 화면이 표시되던 문제를 수정했습니다.
- 일시적인 문제 발생 시 나타나는 복구 화면이 사용자의 언어 설정에 맞게 표시되도록 개선했습니다.
- 이전에는 아무 안내 없이 조용히 실패하던 동작에 실패 안내 메시지를 추가했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
