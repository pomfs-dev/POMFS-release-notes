Date: 2026-08-24
Component: Web
Status: deployed

## Summary
동시에 이용이 몰리는 상황에서 생기던 오류와 중복 알림을 바로잡고, 보안과 접근성을 강화했습니다.

## Changes
- 같은 입장 QR이 동시에 스캔될 때 입장이 중복으로 처리될 수 있던 문제를 수정했습니다.
- 게스트 명단 승인과 공동 호스트 초대가 정원을 넘어 처리될 수 있던 문제와, 참석·고려중 버튼을 빠르게 두 번 누르면 중복 저장되던 문제를 수정했습니다.
- 앱과 웹을 함께 쓰는 계정에 공지 알림이 두 번 발송되던 문제를 수정했습니다.
- 접속이 몰리는 순간 로그인에 실패할 수 있던 문제를 수정하고, 화면 낭독기 이용 환경과 잘 안 보이던 저대비 요소를 개선했으며, 보안을 강화했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
