# r1.56.141 - Web

Date: 2026-10-08
Component: Web
Status: deployed

## Summary
예약형 서비스 주문을 관리자가 결제 취소(환불)할 수 있게 되었고, 예약 정보 표시도 보완했습니다.

## Changes
- 관리자 화면에서 예약형 서비스 주문의 결제를 직접 취소(환불)할 수 있는 버튼을 추가했습니다.
- 결제사에서 취소가 완료된 주문에는 '결제사에서 취소됨' 표시가 나타나 처리 상태를 한눈에 확인하실 수 있습니다.
- 관리자 주문 화면에 영수증과 예약 정보를 표시하고, 예약형 주문에서는 불필요한 승인 버튼을 숨겼습니다.
- 내 신청 내역에서 예약 금액을 확인할 수 있으며, 예약형 서비스의 가격 단위가 '/시간'으로 올바르게 표시됩니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
