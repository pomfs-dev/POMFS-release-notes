# r1.56.74 - Web

Date: 2026-08-31
Component: Web
Status: deployed

## Summary
지도와 목록에서 원하는 기간의 공연을 빠짐없이 찾을 수 있도록 개선하고, 공연 정보 표시 오류를 바로잡았습니다.

## Changes
- 지도와 목록에 '전체' 기간 보기를 추가하고, '이번 주말' 보기에서 주말 당일 공연이 표시되지 않던 문제를 수정했습니다.
- 공연 상세 정보를 불러오는 중 일시적인 문제가 생겼을 때 존재하지 않는 공연으로 잘못 안내하던 문제를 수정했습니다.
- 이미 종료된 공연에 남아 있던 남은 수량·구매 수량 안내 문구를 제거했습니다.
- 홈 화면 대표 이미지를 불러오지 못했을 때 빈 이미지가 그대로 남던 문제를 수정했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
