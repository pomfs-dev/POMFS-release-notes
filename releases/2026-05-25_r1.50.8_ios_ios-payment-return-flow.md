# r1.50.8 - iOS

Date: 2026-05-25
Released at: 2026-05-25 05:38 KST
Component: iOS
Status: deployed

## Summary
iOS 앱에서 Npay와 Toss 결제 후 POMFS 화면으로 돌아오는 흐름을 보강했습니다.

## Changes
- iOS 앱에서 Npay와 Toss 결제 중 필요한 결제 도메인과 앱 열기 스킴 처리를 보강했습니다.
- 결제 후 앱으로 돌아올 때 열린 결제창을 닫고 메인 화면으로 이동하도록 처리했습니다.
- 앱 시작 시 남아 있던 결제 링크가 다음 실행에 재사용되지 않도록 정리했습니다.

## Known Issues
- 이 변경은 iOS 앱 소스 변경이므로 실제 사용자는 새 앱 빌드 설치 후 확인해야 합니다.
- 현재 작업 환경에는 전체 Xcode가 없어 로컬 아카이브 빌드는 수행하지 못했습니다.
