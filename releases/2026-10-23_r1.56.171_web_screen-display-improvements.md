# r1.56.171 - Web

Date: 2026-10-23
Component: Web
Status: deployed

## Summary
여러 화면에서 잘못 보이던 표시를 바로잡고 공연장 관련 화면의 불러오기 속도를 개선했습니다.

## Changes
- 노치가 있는 기기에서 상단바 내용이 본문을 덮던 문제를 고쳤습니다.
- 홈 상단의 숫자 정보를 불러오지 못했을 때 임의의 숫자가 정상 값처럼 표시되던 문제를 바로잡았습니다.
- 공연장 이름이 '온쉼표 (온쉼표)'처럼 같은 이름을 괄호로 반복해 보이던 문제를 고쳤습니다.
- 서비스 상세의 소개가 요약 문구만 반복하던 문제를 고쳐 상세 소개가 제대로 보입니다.
- 공연장 목록을 여는 화면들이 불필요한 정보를 한꺼번에 불러오지 않도록 개선해 더 빠르게 열립니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
