# r1.56.185 - Web

Date: 2026-10-26
Component: Web
Status: deployed

## Summary
공연장 화면의 공개 정보 범위를 정리하고 알림 표시를 개선했습니다.

## Changes
- 공연장 화면에서 별점, 평균 점수, 리뷰 수 등 수치 표시를 정리했습니다.
- 리뷰 작성 화면에 별점이 공개되지 않는다는 안내를 추가했습니다.
- 숨김 또는 삭제된 공연장이 공개 목록에 나타나지 않도록 했습니다.
- 제목이 비어 있던 알림에 기본 제목이 표시되도록 했습니다.
- 프로모터·레이블 대시보드와 공개 카드에는 꼭 필요한 정보만 보이도록 간결하게 정리했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
