# r1.55.10 - Web

Date: 2026-07-09
Component: Web
Status: deployed

## Summary
티켓 결제 화면을 정리하고, 국내(Toss) 결제 시 필수 약관 동의 절차를 추가했습니다. 해외 결제 옵션은 준비 중입니다.

## Changes
- 결제 수단을 국내(Toss)와 해외 결제로 명확히 구분해 표시합니다.
- 국내(Toss) 결제 시 필수 약관에 동의해야 결제가 진행되도록 했습니다.
- 결제 화면의 금액·정보 배치를 보기 좋게 정리했습니다.
- 해외 결제 옵션은 준비 중으로 표시됩니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
