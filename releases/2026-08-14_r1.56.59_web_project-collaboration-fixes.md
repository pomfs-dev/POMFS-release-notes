# r1.56.59 - Web

Date: 2026-08-14
Component: Web
Status: deployed

## Summary
프로젝트 관리와 협업 화면의 동작 오류를 수정했습니다.

## Changes
- 내 프로젝트에서 삭제 버튼과 수정 버튼이 눌러도 동작하지 않던 문제를 수정했습니다.
- 모집이 마감된 협업 프로젝트가 계속 '모집중'으로 표시되던 문제를 수정했습니다.
- 협업 커버 이미지가 넓은 화면에서 첫 화면을 가득 채우던 문제를 개선했습니다.
- 아티스트 드롭 카드에 커버 이미지 대신 프로필 사진이 확대되어 표시되던 문제를 수정했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
