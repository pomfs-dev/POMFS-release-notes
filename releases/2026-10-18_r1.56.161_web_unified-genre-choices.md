# r1.56.161 - Web

Date: 2026-10-18
Component: Web
Status: deployed

## Summary
가입과 공연장 신청 화면의 장르 선택지를 하나의 기준으로 통일했습니다.

## Changes
- 가입 화면과 공연장 신청 화면에서 동일한 6가지 장르 분류를 사용하도록 통일했습니다.
- 장르 선택지에 Pop과 Hip-hop을 새로 추가했습니다.
- 화면마다 표기가 조금씩 달랐던 장르 이름을 하나의 표기로 맞췄습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
