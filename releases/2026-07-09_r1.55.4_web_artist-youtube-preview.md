# r1.55.4 - Web

Date: 2026-07-09
Component: Web
Status: deployed

## Summary
아티스트 프로필 음악 탭에 YouTube 채널 링크만 넣어도 최신 영상이 자동으로 재생 미리보기로 뜨도록 인식 범위를 넓혔습니다.

## Changes
- 다양한 형태의 YouTube 링크(채널 주소, 개별 영상 주소 등)에서 최신 영상을 자동으로 찾아 보여줍니다.
- 영상을 불러오는 동안에는 자연스러운 로딩 화면을 표시해 깜빡임을 없앴습니다.
- 영상이 없는 채널은 가운데 정렬된 채널 바로가기 버튼으로 안내합니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
