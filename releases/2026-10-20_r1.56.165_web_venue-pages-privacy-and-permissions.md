# r1.56.165 - Web

Date: 2026-10-20
Component: Web
Status: deployed

## Summary
공연장 화면의 정보 노출과 권한 확인을 정비하고 보안을 강화했습니다.

## Changes
- 숨김 또는 삭제 처리된 공연장이 공개 목록에 나타나지 않도록 수정했습니다.
- 공연장 공연 정보를 등록하거나 수정할 때 해당 공연장의 관리자인지 확인하도록 강화했습니다.
- 공연장 화면에서 불필요한 수치와 리뷰 별점 표시를 정리하고, 공개 화면에 관리자 개인 정보가 노출되지 않도록 했습니다.
- 내 공연장·내 공연 여부를 더 정확하게 판별하여 관리 메뉴가 올바르게 표시됩니다.
- 제목이 비어 있던 알림에 기본 제목이 표시되도록 개선하고, 공연장의 새 공연 알림 전달 안정성을 높였습니다.
- 오류 발생 시 내부 정보가 화면에 노출되지 않도록 하는 등 전반적인 보안을 강화했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
