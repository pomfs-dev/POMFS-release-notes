# 3.0.5 (21) - Android

Date: 2026-09-27
Released at: 2026-09-27 14:34 KST
Component: Android
Status: released

## Summary
일부 안드로이드 기기에서 Google 로그인 시 계정을 선택한 뒤 로그인이 완료되지 않던 문제를 수정했습니다.

## Changes
- Google 로그인 창을 Chrome 이 설치된 기기에서는 Chrome 으로 열도록 변경했습니다.
- Google 계정을 선택한 뒤 메일 작성 화면이 열리며 로그인이 중단되던 현상을 해결했습니다.
- Google Play 프로덕션에 업데이트를 배포했습니다.

## Known Issues
- 앱 업데이트가 기기에 반영되기 전에는 기기의 기본 브라우저를 Chrome 으로 설정하면 로그인할 수 있습니다.
