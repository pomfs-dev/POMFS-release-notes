# r1.56.1 - Web

Date: 2026-07-20
Component: Web
Status: deployed

## Summary
모든 채팅 화면에서 메시지를 번역해 보고, 이모지로 반응할 수 있는 기능을 추가했습니다.

## Changes
- 채팅 메시지에 번역 토글을 추가해 다른 언어로 온 메시지를 바로 번역해 볼 수 있습니다.
- 메시지를 더블탭하면 하트를, 길게 누르면 다양한 이모지 반응을 남길 수 있습니다.
- 번역과 이모지 반응은 전체 채팅, DM, 이벤트 채팅, 함께 즐기기 등 모든 채팅 화면에서 동일하게 사용할 수 있습니다.
- 다른 사람이 남긴 이모지 반응이 실시간으로 화면에 반영되도록 하고, 번역 정확도와 이모지 반응의 위치·말풍선 안 배치 등 세부 디자인도 함께 다듬었습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
