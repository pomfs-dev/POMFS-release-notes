# r1.56.25 - Web

Date: 2026-08-03
Component: Web
Status: deployed

## Summary
등급 신청 관리와 프로모션 코드 발행 화면의 오류를 바로잡았습니다.

## Changes
- 일부 신청 건 때문에 등급 신청 관리 화면이 열리지 않던 문제를 해결했습니다.
- 등급 신청을 거절할 때 입력한 사유가 저장되지 않던 문제를 해결했습니다.
- 프로모션 코드 발행 화면에서 만료일을 입력하실 수 있도록 하고, 사용할 수 없던 선택지를 정리했습니다.
- 등급 부여와 회원 삭제 등 주요 처리 이력이 남도록 하여 운영 내역 확인이 쉬워졌습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
