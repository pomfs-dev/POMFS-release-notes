# r1.56.98 - Web

Date: 2026-09-15
Component: Web
Status: deployed

## Summary
여러 화면에서 정보가 잘못 표시되거나 비어 보이던 오류를 정리했습니다.

## Changes
- 일부 공연 상세 화면에서 내용이 비어 보이거나 주최자 정보, 주소, 라인업 매칭이 어긋나던 문제를 고쳤습니다.
- 공연·공연장 관리 카드에서 이미지가 깨지거나 '티켓 미등록'으로 잘못 안내되던 문제를 고쳤습니다.
- 공연장 프로필 편집 시 저장에 실패했는데도 '저장됨'으로 표시되던 오류와, 일부 화면에서 뜨던 알 수 없는 오류 문구를 정리했습니다.
- 지도에서 위치 표시 효과가 아이콘 중심을 벗어나 보이던 부분과 아티스트 드롭 대표 이미지가 넓은 화면에서 과하게 잘리던 부분을 정리했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
