# r1.56.37 - Web

Date: 2026-08-10
Component: Web
Status: deployed

## Summary
채팅과 알림, 공유 문구가 제대로 보이도록 여러 표시 문제를 수정했습니다.

## Changes
- 채팅에서 다른 참여자를 언급하는 기능이 동작하지 않거나 채널을 옮긴 뒤 입력 상태가 남던 문제, 마지막 메시지가 입력창에 가려 보이지 않던 문제, 연결이 끊긴 뒤 한동안 다시 참여할 수 없던 문제를 수정했습니다. 이벤트 채팅 화면에 제목이 두 번 표시되던 문제도 함께 정리했습니다.
- 알림과 공유 문구가 중간에서 어색하게 끊기거나 말줄임표 없이 잘리던 문제를 수정하고, 새 글 하나에 알림이 중복으로 발송되던 문제를 해결했습니다.
- 선택한 앱 언어가 약관 등 법률 문서 본문과 게시물 메뉴에도 적용됩니다.
- 일부 배지와 필터의 글자가 배경에 묻혀 읽기 어려웠던 문제를 수정하고, 화면 낭독 기능의 안내를 보강했으며, 안내 문구를 길게 눌렀을 때 불필요한 메뉴가 뜨거나 키보드가 입력 영역을 가리던 문제를 개선했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
