# r1.56.170 - Web

Date: 2026-10-23
Component: Web
Status: deployed

## Summary
프로젝트 모집과 입력 화면에서 발생하던 여러 불편을 바로잡았습니다.

## Changes
- 프로젝트 작성 시트에서 제목을 눌렀을 때 키보드와 함께 입력 칸이 화면 밖으로 밀려 사라지던 문제를 고쳤습니다.
- 키보드가 열려 있을 때 하단 시트가 화면 위쪽까지 올라오고, 버튼 아래 여백이 불필요하게 남지 않도록 개선했습니다.
- 채팅 목록의 모집 마감 표시와 프로젝트 설명 글자 수 제한 안내를 정확하게 맞췄습니다.
- 응답이 오지 않는 요청이 계속 대기하던 문제를 개선했고, 모집 상태가 의도치 않게 바뀌지 않도록 보호했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.

- None.
