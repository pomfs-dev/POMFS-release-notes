# r1.50.16 - Web

Date: 2026-05-28
Released at: 2026-05-28 17:12 KST
Component: Web
Status: deployed

## Summary
티켓 구매에서 PayPal 결제 승인 화면으로 이동하는 방식을 조정해 결제 테스트 중 PayPal 오류 페이지가 열리던 문제를 완화했습니다.

## Changes
- PayPal 티켓 결제에서 브라우저 내 PayPal 버튼 경로 대신 서버가 생성한 PayPal 승인 페이지로 이동하도록 변경했습니다.
- PayPal 결제 안내 문구를 실제 이동 방식에 맞게 정리했습니다.
- 프로덕션 커뮤니티 웹 서비스를 새 결제 화면 번들로 롤링 배포했습니다.
- 운영 배포 후 커뮤니티 웹 헬스 체크, 새 번들 반영, 딥링크 설정 응답, 서비스 상태를 확인했습니다.

## Known Issues
- PayPal 계정 국가, 계정 상태, 카드 발급사 정책에 따라 PayPal 승인 단계에서 결제가 거절될 수 있습니다.
- 이미 열려 있던 결제 화면은 앱을 완전히 종료하거나 새로고침한 뒤 다시 결제를 시작해야 최신 PayPal 경로를 사용할 수 있습니다.
