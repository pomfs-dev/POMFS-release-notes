# r1.52.13 - Web

Date: 2026-06-07
Released at: 2026-06-07 18:56 KST
Component: Web
Status: deployed

## Summary
피드의 큐레이션 글에도 댓글로 의견을 나눌 수 있도록 댓글 기능을 추가했습니다.

## Changes
- MiSFY가 소개하는 공연 영상 큐레이션 글에 댓글을 남길 수 있도록 댓글 기능을 새로 추가했습니다.
- 일반 글과 동일하게 다른 사용자의 댓글에 답글을 달 수 있습니다.
- 마음에 드는 댓글에 좋아요를 누를 수 있습니다.
- 댓글에 이미지나 링크를 함께 첨부할 수 있습니다.
- 기존에 작성된 글에는 영향 없이 그대로 이용할 수 있습니다.
- 위 변경 사항을 운영 환경에 배포하고 정상 동작을 확인했습니다.

## Known Issues
- 댓글 작성, 답글, 좋아요는 로그인 후 이용할 수 있습니다.
