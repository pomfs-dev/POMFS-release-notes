# r1.56.30 - Web

Date: 2026-08-10
Component: Web
Status: deployed

## Summary
아티스트 프로필과 공개 카드에 실제 활동 정보가 정확히 표시되도록 개선했습니다.

## Changes
- 아티스트 프로필 상단에 임시로 보이던 예시 정보를 실제 활동 정보로 교체했습니다.
- 장르가 비어 보이거나 갤러리 이미지가 표시되지 않던 문제를 해결했습니다.
- 소개글을 펼쳐 전체 내용을 확인하실 수 있고, 프로필을 수정할 때 기존 장르가 그대로 채워집니다.
- 등급 신청 시 제출한 갤러리와 소개 자료가 승인 이후 공개 카드에 반영됩니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
