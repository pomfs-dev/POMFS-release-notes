# r1.56.60 - Web

Date: 2026-08-14
Component: Web
Status: deployed

## Summary
좋아요와 즐겨찾기의 표시·동작 오류를 수정했습니다.

## Changes
- 게시물을 즐겨찾기에 저장해도 항상 꺼진 상태로 표시되던 문제를 수정했습니다.
- 게시물과 이벤트 상세 화면에서 좋아요 상태와 개수가 실제와 다르게 표시되던 문제를 수정했습니다.
- 리스너 프로필에서 게시물의 좋아요·댓글 버튼이 동작하지 않던 문제를 수정했습니다.
- 좋아요 목록에서 눌러도 아무 동작이 없던 버튼을 정리했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
