# r1.56.179 - Web

Date: 2026-10-25
Component: Web
Status: deployed

## Summary
아티스트 드롭과 프로필에서 직접 수정할 수 있는 항목이 크게 늘었습니다.

## Changes
- 아티스트 드롭 편집에서 프로필 사진, 공개 주소, 여러 장의 커버 이미지, 세부 장르, 대표 계정, 틱톡 아이디를 수정할 수 있게 했습니다.
- 프로필의 틱톡 아이디를 신청서 재제출 없이 수정할 수 있게 했습니다.
- 로그인하지 않은 상태에서 구독을 누르면 로그인 후 자동으로 구독이 완료되도록 했습니다.
- 공개 카드의 링크 영역이 SNS 링크 스위치와 별개로 표시되도록 분리했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
