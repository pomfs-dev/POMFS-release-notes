# r1.51.4 - Web

Date: 2026-06-05
Released at: 2026-06-05 00:15 KST
Component: Web
Status: deployed

## Summary
개인정보처리방침과 이용약관을 관련 법 기준에 맞게 보강하고, 법률 페이지에서 한국어와 영어를 바로 전환해 볼 수 있게 했습니다.

## Changes
- 개인정보처리방침과 이용약관 내용을 관련 법 기준에 맞춰 보강했습니다.
- 사업자 정보를 함께 기재해 회사 정보를 확인할 수 있도록 했습니다.
- 법률 페이지에서 한국어와 영어를 버튼으로 전환해 볼 수 있는 토글을 추가했습니다.
- 약관 이해를 돕기 위한 한국어 참고 번역을 제공합니다.
- 이 언어 전환은 법률 페이지에서만 적용되며, 앱 전체 언어 설정에는 영향을 주지 않습니다.
- 변경 사항은 운영 환경에 배포되어 정상 동작을 확인했습니다.
