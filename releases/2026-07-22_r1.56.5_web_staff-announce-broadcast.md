# r1.56.5 - Web

Date: 2026-07-22
Component: Web
Status: deployed

## Summary
스태프가 채팅에서 '공지로 보내기'를 켜고 메시지를 보내면 아티스트·공연장·스태프 전원에게 알림이 발송됩니다.

## Changes
- 스태프 전용 '공지로 보내기' 스위치를 채팅에 추가했습니다.
- 공지 발송 시 아티스트·공연장·스태프 전원에게 알림이 전달됩니다.
- 공지를 한 번 보내면 스위치가 자동으로 꺼져 실수로 반복 발송되는 것을 방지합니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
