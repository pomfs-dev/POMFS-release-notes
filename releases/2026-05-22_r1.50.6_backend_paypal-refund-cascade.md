# r1.50.6 - Backend

Date: 2026-05-22
Released at: 2026-05-22 23:27 KST
Component: Backend
Status: deployed

## Summary
PayPal로 결제한 티켓도 환불 완료 후 안내 메일, 공연 생성자 알림, 환불 상태 표시가 Toss 결제와 같은 흐름으로 처리되도록 보강했습니다.

## Changes
- PayPal 티켓 환불 완료 후 구매자에게 환불 완료 메일이 가는 흐름을 확인하고 보강했습니다.
- PayPal 환불 완료 시 운영자 안내 메일과 공연 생성자 알림이 함께 처리되도록 검증했습니다.
- PayPal 부분 환불은 결제 당시 통화와 금액을 기준으로 환불 요청 금액을 계산하도록 정리했습니다.
- 환불된 PayPal 티켓이 공연 관리와 티켓 목록에서 환불 상태로 표시되도록 서버 상태 전이를 검증했습니다.

## Known Issues
- 이미 열린 앱 화면은 이전 캐시를 볼 수 있으므로 환불 직후 화면을 새로 열어야 최신 상태가 보일 수 있습니다.
