# r1.52.2 - Backend

Date: 2026-06-05
Released at: 2026-06-05 10:05 KST
Component: Backend
Status: deployed

## Summary
같은 이메일 주소로 서로 다른 로그인 방식을 쓰면 별개의 계정이 따로 만들어지던 문제를 개선해, 한 사람이 하나의 계정으로 일관되게 이용할 수 있도록 회원가입·로그인 처리를 강화했습니다.

## Changes
- 구글·애플·이메일 등 로그인 방식이 달라도 같은 이메일 주소면 동일한 사용자로 인식하도록 정리했습니다.
- 이메일 주소의 대소문자 차이만으로 같은 사람이 다른 계정으로 처리되던 경우를 방지했습니다.
- 일시적인 오류 상황에서 의도치 않게 새 계정이 만들어지지 않도록 안전장치를 추가했습니다.
- 이미 가입한 이메일로 다른 로그인 방식을 사용할 때, 새 계정을 만드는 대신 기존 계정으로 안전하게 이어지도록 처리했습니다(본인 확인이 가능한 경우에 한함).
- 운영 환경에 배포하고 정상 동작을 확인했습니다.

## Known Issues
- 애플 로그인에서 '이메일 가리기(비공개 주소)'를 처음 사용하는 경우에는 기존 계정과 자동으로 연결되지 않을 수 있으며, 추후 계정 연결 기능을 통해 보완할 예정입니다.
- 이번 개선은 앞으로 생성되는 계정에 적용되며, 과거에 중복 생성된 계정의 정리는 별도로 진행될 수 있습니다.
