# r1.55.0 - Web

Date: 2026-07-08
Component: Web
Status: deployed

## Summary
전체 채팅(채널)에서도 사진을 첨부해 보낼 수 있도록 했습니다. 그동안 개인 메시지에서만 가능하던 사진 전송을 커뮤니티 채팅으로 넓혔습니다.

## Changes
- 채팅 입력창에 사진 첨부 버튼을 추가해, 대화 중 바로 사진을 골라 보낼 수 있게 했습니다.
- 사진을 고르면 보내기 전에 미리보기로 확인하고 취소할 수 있습니다.
- 받은 사진은 대화 말풍선에서 바로 보이고, 눌러서 크게 볼 수 있습니다.
- 여러 언어 화면에서 동일하게 동작하도록 문구를 정리했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
