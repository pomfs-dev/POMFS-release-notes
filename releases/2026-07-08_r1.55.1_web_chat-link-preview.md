# r1.55.1 - Web

Date: 2026-07-08
Component: Web
Status: deployed

## Summary
채팅 메시지 속 링크를 자동으로 눌러서 열 수 있게 하고, 링크의 제목·설명·이미지를 담은 미리보기 카드를 함께 보여줍니다.

## Changes
- 메시지에 붙여넣은 링크를 자동으로 인식해 바로 눌러서 열 수 있게 했습니다.
- 링크 아래에 제목·설명·대표 이미지가 담긴 미리보기 카드를 표시합니다.
- 카드를 누르면 해당 페이지로 이동합니다.
- 이미 앱에서 지원하는 영상·SNS 링크는 기존 방식대로 표시되도록 정리했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
