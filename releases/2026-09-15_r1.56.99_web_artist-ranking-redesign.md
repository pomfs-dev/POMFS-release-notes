# r1.56.99 - Web

Date: 2026-09-15
Component: Web
Status: deployed

## Summary
아티스트 랭킹 화면의 정렬과 표시 방식을 다듬었습니다.

## Changes
- 랭킹 탭의 정렬 순서를 조정하고, MiSFY 기준을 기본으로 유지하면서 다른 등급도 함께 선택해 볼 수 있게 했습니다.
- 인스타그램을 연동하지 않은 아티스트는 '인스타그램 미입력' 상태로 따로 표시됩니다.
- 아직 점수가 산정되지 않은 아티스트는 순위 번호에서 제외되어 순위 집계가 더 정확해졌습니다.
- 점수 비공개 아티스트의 안내 문구와 랭킹 아바타의 MiSFY 표시를 다듬었습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
