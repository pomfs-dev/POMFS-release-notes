# r1.56.72 - Web

Date: 2026-08-24
Component: Web
Status: deployed

## Summary
아티스트 구독자 수와 내 구독 목록, 선호 장르, 랭킹이 실제와 다르게 표시되던 문제를 수정했습니다.

## Changes
- 아티스트 구독자 수가 실제보다 적게 표시되고, 마이페이지의 구독 아티스트 목록에서 일부가 빠지던 문제를 수정했습니다.
- 프로필의 선호 장르 선택지가 일부만 노출되던 문제와 장르 필터 아이콘이 서로 뒤바뀌어 보이던 문제를 수정했습니다.
- 아티스트 랭킹의 티켓 집계가 실제 판매와 다르게 계산되던 문제를 수정했습니다.
- 좋아요 목록의 글 카드에 첨부 이미지가 보이지 않고 글 상세로 이동할 수 없던 문제를 수정했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
