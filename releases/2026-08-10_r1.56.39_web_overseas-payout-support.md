# r1.56.39 - Web

Date: 2026-08-10
Component: Web
Status: deployed

## Summary
해외 42개국에서 정산 계정을 등록하고 수익을 받을 수 있게 되었습니다.

## Changes
- 해외 42개국에서 정산 계정 등록이 가능해지고, 선택한 국가에 맞는 정산 방식을 안내합니다. 일부 국가는 관련 법규와 서비스 정책에 따라 이용이 제한될 수 있습니다.
- 해외 정산 등록 과정에서 진행이 중단되던 문제와 국가 목록에 같은 항목이 중복으로 보이던 문제를 수정했습니다.
- 프로필을 수정할 때 저장해 둔 국가 정보가 지워져 정산 방식 판단에 영향을 주던 문제를 해결했습니다.
- 결제 완료 시 영수증을 이메일로 보내드리며, 같은 결제가 중복 처리되지 않도록 보완했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
