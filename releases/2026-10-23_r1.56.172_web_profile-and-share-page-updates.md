# r1.56.172 - Web

Date: 2026-10-23
Component: Web
Status: deployed

## Summary
공연장 프로필과 공유 페이지의 구성과 화면 대응을 개선했습니다.

## Changes
- 공연장 계정의 프로필에 '주최한 이벤트' 영역이 추가되어 열었던 이벤트를 한눈에 볼 수 있습니다.
- 리스너 공개 주소 페이지의 색상 테마를 통일하고, 복사 버튼을 6개 언어로 지원합니다.
- 아티스트 공유 명함 카드가 PC 화면에서 지나치게 넓어지던 문제를 고쳤습니다.
- 공연장 신청 화면의 미니맵이 데스크톱에서 납작하게 보이던 문제를 화면 크기에 맞게 개선했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
