# r1.53.5 - Web

Date: 2026-06-13
Component: Web
Status: deployed

## Summary
외부로 공유한 공연 링크를 열면 화면이 비어 보이던 문제를 해결했습니다.

## Changes
- 공유한 공연 링크를 열었을 때 내용이 보이지 않고 빈 화면이 나타나던 문제를 수정했습니다.
- 이제 공유 링크에서 공연 정보가 정상적으로 표시되고, 앱에서 바로 열 수 있는 안내가 함께 나타납니다.
- 링크 미리보기(제목·이미지) 동작은 그대로 유지됩니다.
- 운영 배포 후 정상 동작을 확인했습니다.
