## Summary
여러 화면에서 내용이 가려지거나 어긋나 보이던 표시 오류를 모아 수정했습니다.

## Changes
- 공유 링크로 연 글의 윗부분이 상단 메뉴에 가려지던 문제를 수정했습니다.
- 삭제된 영상의 미리보기가 빈 회색 카드로 남아 보이던 문제를 수정했습니다.
- 첫 화면의 배너와 일부 이미지 영역이 지나치게 크게 표시되어 화면을 차지하던 문제를 수정했습니다.
- 이벤트 채팅 화면의 상단 바가 두 겹으로 보이던 문제와, 종료된 공연 화면의 중복 안내, 일부 화면의 제목 중복·정렬 어긋남을 수정했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
