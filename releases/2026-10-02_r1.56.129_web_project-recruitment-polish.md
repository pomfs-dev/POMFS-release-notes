# r1.56.129 - Web

Date: 2026-10-02
Component: Web
Status: deployed

## Summary
프로젝트 모집 화면의 입력 창과 목록 표시, 모집 상태 관리를 안정적으로 개선했습니다.

## Changes
- 프로젝트 관련 입력 창에서 제목 칸을 누르면 키보드와 함께 창이 밀려 올라가 입력 칸이 사라지던 문제를 해결했습니다.
- 키보드가 열려 있을 때 하단 입력 창이 화면 위쪽까지 올라오던 문제와 버튼 아래 불필요한 여백을 바로잡았습니다.
- 채팅 목록에서 모집 마감 여부가 정확하게 표시되도록 하고, 프로젝트 설명 글자 수 제한이 머리말을 포함해 올바르게 계산되도록 개선했습니다.
- 프로젝트 카드 버튼의 안내 문구를 정확하게 다듬었고, 응답이 오지 않는 요청은 일정 시간 후 중단되어 화면이 멈춘 것처럼 보이지 않게 했습니다.
- 모집 상태가 의도하지 않은 방식으로 바뀌지 않도록 프로젝트 수정 절차를 더 엄격하게 점검했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
