# r1.56.29 - Web

Date: 2026-08-10
Component: Web
Status: deployed

## Summary
'나의 등급' 화면을 신청 상태에 맞춰 개편하고 신청 자료 첨부 과정을 개선했습니다.

## Changes
- '나의 등급' 화면을 신청 상태에 맞춰 다시 구성하고, 아직 제공되지 않는 항목은 정리했습니다.
- 신청 자격이 되지 않는 경우 신청 화면에 들어갈 때 안내를 드리도록 했습니다.
- 갤러리 이미지는 최대 10장까지 등록하고 언제든 삭제하실 수 있으며, 소개 자료는 최대 3개까지 첨부하실 수 있습니다.
- 첨부한 갤러리와 소개 자료가 저장되지 않던 문제를 해결하고, 올리지 못한 항목만 완료 화면에서 다시 올릴 수 있도록 했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
