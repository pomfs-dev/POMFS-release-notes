Date: 2026-07-10
Component: Web

## Summary
티켓 환불 신청이 접수돼도 화면에 아무 안내가 없어 여러 번 눌리던 문제를 수정했습니다.

## Changes
- 환불 신청이 접수되면 "관리자 승인 후 환불됩니다" 안내를 표시합니다.
- 같은 주문에 이미 처리 대기 중인 환불이 있으면 중복 신청을 막고 안내합니다.
- 연속 클릭으로 신청이 중복 접수되던 문제를 화면과 서버 양쪽에서 차단했습니다.
