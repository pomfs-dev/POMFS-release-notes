# r1.53.10 - Web

Date: 2026-06-18
Component: Web
Status: deployed

## Summary
공연 주최자 계정이 삭제되어도, 구매한 티켓에 구매 당시의 주최자 이름이 그대로 표시되도록 했습니다.

## Changes
- 티켓 구매 시점의 주최자(이벤트 등록자) 이름을 주문에 함께 저장합니다.
- 이후 주최자 계정이 삭제되더라도 티켓 상세 화면에 당시 주최자 이름이 유지됩니다.
- 기존 주문도 주최자 계정이 남아 있는 경우 주최자 이름을 채워 넣었습니다.
- 주최자 정보가 전혀 없는 경우에만 "-"로 표시되며, 구매자 이름이 주최자로 잘못 표시되지 않습니다.
- 변경 사항이 배포되었으며 정상 동작을 확인했습니다.
