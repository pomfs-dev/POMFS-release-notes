# r1.56.0 - Web

Date: 2026-07-20
Component: Web
Status: deployed

## Summary
함께 즐기기가 공연 지도와 하나로 통합되어, 지도에서 바로 모임을 찾고 공연 카드에서 곧장 모임을 만들거나 참여할 수 있게 되었습니다.

## Changes
- 공연 지도에서 모드를 전환해 공연 보기와 함께 즐기기 모임 보기를 오갈 수 있습니다.
- 지도 화면 아래에서 주변 모임 목록을 한눈에 확인할 수 있는 목록 화면을 추가했습니다.
- 공연 카드가 함께 즐기기의 허브가 되어, 카드에서 바로 모임 만들기와 참여가 가능합니다.
- 모임 만들기 화면을 더 간단하게 정리하고, 분류가 자동으로 채워지며 공연과 연결된 모임만 골라볼 수 있는 필터를 추가했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
