# r1.56.23 - Web

Date: 2026-08-03
Component: Web
Status: deployed

## Summary
첫 화면과 공연 목록에서 공연이 빠지거나 잘못 보이던 문제를 바로잡았습니다.

## Changes
- 첫 화면 공연 모음에서 이미 지난 공연은 제외하고, 날짜가 가까운 순서로 보여드립니다.
- 날짜가 먼 공연이 목록에 나타나지 않던 문제를 해결했습니다.
- 시간이 정해지지 않은 공연은 시간 자리에 '종일'로 표시됩니다.
- 공연 목록의 소개 미리보기에서 이모지 등 일부 글자가 깨져 보이던 문제를 해결했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
