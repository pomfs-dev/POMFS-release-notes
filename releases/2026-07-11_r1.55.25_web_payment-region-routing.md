# r1.55.25 - Web

Date: 2026-07-11
Component: Web
Status: deployed

## Summary
티켓 결제 화면에서 결제사 선택 버튼을 없애고, 지역에 따라 결제 방식을 자동으로 정하도록 바꿨습니다.

## Changes
- 결제 서비스 선택(2버튼)을 제거하고 지역 기준으로 자동 라우팅합니다: 국내 사용자는 토스, 해외 사용자는 Stripe 카드 결제.
- 국내 사용자라도 외화 공연은 안전하게 해외 결제 경로로 넘어갑니다.
- 로그인하지 않은 사용자는 국내(토스)를 기본값으로 사용합니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
