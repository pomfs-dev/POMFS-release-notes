# r1.56.66 - Web

Date: 2026-08-17
Component: Web
Status: deployed

## Summary
글 작성 추천 속도를 높이고, 좋아요 목록·공유 링크·검색 화면 등의 표시 오류를 수정했습니다.

## Changes
- 글 작성 시 멘션(@)과 이벤트 태그(#) 추천 목록이 훨씬 빠르게 나타나도록 개선했습니다.
- 좋아요 목록에 AI 추천 글이 표시되지 않던 문제와, 공유 링크로 연 공연 상세 화면을 닫으면 빈 화면으로 이동하던 문제를 수정했습니다.
- 인기 아티스트의 구독자 수 표기와 공연장 상세의 '예정 공연' 안내 표시를 알아보기 쉽게 바로잡았습니다.
- 인스타그램 연동 가이드로 이동하는 경로를 추가하고, 그룹 채팅 화면의 번역 누락을 보완했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
