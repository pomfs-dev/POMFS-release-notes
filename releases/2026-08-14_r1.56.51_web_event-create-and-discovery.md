# r1.56.51 - Web

Date: 2026-08-14
Component: Web
Status: deployed

## Summary
공연 등록 시 날짜와 시간을 화면에서 바로 선택할 수 있고, 지도와 공연 목록이 더 정확하게 표시됩니다.

## Changes
- 공연을 등록할 때 날짜와 시간을 화면에서 바로 선택할 수 있으며, 등록한 공연을 수정할 때도 달력을 사용할 수 있습니다.
- 지도에서 장르 정보가 없는 공연장도 눈에 잘 띄는 색으로 표시되고, 지도 핀의 미리보기에는 해당 공연장·아티스트의 대표 이미지만 보여 드립니다.
- 같은 공연이 목록에 두 번 나오거나, 오후 늦은 시간에 날짜가 하루 밀려 보이거나, 검색에서 다가오는 공연이 없다고 잘못 안내되거나, 내부 확인용 공연이 노출되던 문제를 모두 바로잡았습니다.
- 게스트리스트 신청 화면이 키보드에 가려 입력이 어려웠던 문제를 수정했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
