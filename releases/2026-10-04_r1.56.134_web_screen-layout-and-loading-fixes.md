# r1.56.134 - Web

Date: 2026-10-04
Component: Web
Status: deployed

## Summary
공유 명함 카드, 공연장 신청 지도, 공연장 관련 화면, 공유 이미지 표시를 개선했습니다.

## Changes
- PC 화면에서 공유 명함 카드가 지나치게 넓게 늘어나던 문제를 고쳐 적정 폭으로 표시합니다.
- 공연장 신청 화면의 지도가 PC에서 납작하게 보이던 문제를 고쳐 화면 크기에 맞는 높이로 표시합니다.
- 공연장 정보를 보여주는 여러 화면의 불러오기 방식을 정리해 더 빠르게 열리도록 개선했습니다.
- 공유용 이미지와 아티스트 소개 페이지가 간헐적으로 생성되지 않던 문제를 해결했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
