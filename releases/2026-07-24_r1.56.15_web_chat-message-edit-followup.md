# r1.56.15 - Web

Date: 2026-07-24
Component: Web
Status: deployed

## Summary
채팅 메시지 수정 기능에서 발생하던 불편을 개선했습니다.

## Changes
- 다른 대화로 이동한 뒤에도 수정 상태가 남아 메시지가 보내지지 않던 문제를 해결했습니다(그룹 채팅과 공연 채팅 포함).
- 메시지를 수정하는 중에는 멘션을 선택할 수 없도록 하여, 알림이 가지 않는 멘션으로 오해하는 일을 방지했습니다.
- 삭제된 메시지에 '수정됨' 표시가 남아 있던 문제를 바로잡았습니다.
- 채팅 메시지 수정 과정의 보안을 강화했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
