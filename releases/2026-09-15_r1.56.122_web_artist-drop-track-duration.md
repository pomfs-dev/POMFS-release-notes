# r1.56.122 - Web

Date: 2026-09-15
Component: Web
Status: deployed

## Summary
아티스트 드롭 카드에서 대표곡의 재생 시간과 대표 계정 여부를 확인할 수 있습니다.

## Changes
- 아티스트가 대표곡을 등록할 때 곡의 재생 시간을 함께 입력할 수 있도록 했습니다.
- 대표곡 카드 하단에 재생 시간과 음원 출처가 함께 표시됩니다(예: 3:42 · YouTube).
- 공개된 아티스트 드롭 카드에서 대표 계정 여부를 확인할 수 있도록 표시를 추가했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
