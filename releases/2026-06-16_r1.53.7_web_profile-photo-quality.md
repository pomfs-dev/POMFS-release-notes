# r1.53.7 - Web

Date: 2026-06-16
Component: Web
Status: deployed

## Summary
프로필 사진을 더 높은 화질로 저장하도록 개선해, 아티스트·리스너 프로필 카드의 큰 배경 이미지가 또렷하게 보입니다.

## Changes
- 프로필 사진을 편집(크롭)하면 작은 프로필 아이콘과 큰 배경 이미지가 각각 알맞은 크기로 따로 저장됩니다.
- 아티스트·리스너 프로필 카드 상단의 큰 배경 이미지가 더 선명하게 표시됩니다. 이전에는 작은 이미지가 확대되어 흐릿하게 보였습니다.
- 가입 과정과 프로필 설정 양쪽에서 동일하게 적용됩니다.
- 변경 사항이 앱에 배포되었습니다.

## Known Issues
- 이전에 등록한 프로필 사진은 한 번 다시 편집(크롭)해야 새 화질로 적용됩니다.
