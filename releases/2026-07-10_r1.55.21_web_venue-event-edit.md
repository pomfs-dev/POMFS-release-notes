# r1.55.21 - Web

Date: 2026-07-10
Component: Web
Status: deployed

## Summary
공연장 관리에서 등록한 공연의 수정 버튼이 동작하지 않던 문제를 수정했습니다.

## Changes
- 공연장 관리의 공연 수정 버튼을 실제 편집 화면으로 연결했습니다.
- 공연장 공연 편집 화면을 신설해 이름·날짜·상세 내용·이미지·외부 링크를 수정할 수 있습니다.
- 이미 판매된 티켓 보호를 위해 티켓·게스트리스트 설정은 편집에서 변경할 수 없도록 안내합니다.
- 공연장 공연은 단일 날짜만 지원하므로 날짜 추가 버튼을 정리해 입력 유실을 방지했습니다.
