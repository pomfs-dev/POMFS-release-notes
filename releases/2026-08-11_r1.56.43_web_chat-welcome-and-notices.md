# r1.56.43 - Web

Date: 2026-08-11
Component: Web
Status: deployed

## Summary
채팅방 입장 안내와 신규 회원 환영 메시지를 추가하고 운영진 공지 범위를 넓혔습니다.

## Changes
- 채팅방에 새로운 참여자가 들어오면 '님이 채팅방에 들어왔습니다' 안내가 표시됩니다.
- 새로 가입한 회원에게 환영 메시지가 자동으로 전달됩니다.
- 전체 채널을 포함한 모든 채팅 채널에서 운영진 공지를 설정할 수 있습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
