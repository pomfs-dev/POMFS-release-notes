# r1.53.0 - Web

Date: 2026-06-08
Component: Web
Status: deployed

## Summary
Today 화면의 "새로운 공연"을 내 주변과 가까운 날짜를 기준으로 똑똑하게 추천하도록 개선했습니다.

## Changes
- Today 화면의 "새로운 공연" 영역이 내 주변에서 다가오는 공연을 우선 보여주도록 개편했습니다.
- 날짜가 가까운 공연을 앞쪽에 배치해, 더 빨리 즐길 수 있는 공연부터 한눈에 확인하실 수 있습니다.
- 이전에는 먼 미래의 공연이 순서 없이 앞에 노출되던 점을 정리해, 보기 편한 순서로 정렬했습니다.
- 실제로 다가오는 공연 정보를 바탕으로 보여드려, 빈 화면 없이 진행 예정인 공연이 표시됩니다.
- 위 변경 사항을 운영 환경에 배포하고 정상 동작을 확인했습니다.

## Known Issues
- 위치 권한을 허용하면 내 주변 공연이 우선 표시되며, 허용하지 않은 경우에는 날짜와 지역을 기준으로 정렬해 보여줍니다.
