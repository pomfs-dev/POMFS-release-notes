# r1.56.6 - Web

Date: 2026-07-22
Component: Web
Status: deployed

## Summary
채팅에서 줄바꿈 입력, 길게 눌러 반응하기, 이모지 선택창 표시가 더 자연스럽게 동작하도록 개선했습니다.

## Changes
- 채팅 입력창에서 Enter 키를 누르면 메시지가 바로 전송되지 않고 줄바꿈이 되도록 변경했습니다. 전송은 전송 버튼으로 진행됩니다.
- 메시지를 길게 눌러 반응을 남길 때 화면의 글자가 함께 선택되어 버리던 문제를 수정했습니다.
- 이모지 선택창이 화면 가장자리에서 일부 잘려 보이던 문제를 수정했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
