# r1.53.9 - Backend

Date: 2026-06-16
Component: Backend
Status: deployed

## Summary
아티스트 등업이 승인된 뒤에도 프로필에 장르가 "기타"로 보이거나 자기소개가 비어 있던 문제를 해결해, 등업 신청 시 입력한 정보가 프로필에 그대로 반영되도록 했습니다.

## Changes
- 아티스트 등업이 승인되면, 신청할 때 입력한 장르·세부 역할·자기소개가 프로필에 자동으로 반영됩니다.
- 기존에는 프로필의 장르가 비어 "기타"로 표시되거나 자기소개가 공란으로 남던 문제가 있었으며, 이를 수정했습니다.
- 이미 등업이 완료된 아티스트의 프로필 정보도 함께 보정해, 빠진 장르·자기소개가 채워지도록 했습니다.
- 운영 배포 후 정상 동작을 확인했습니다.
