# r1.52.8 - Web

Date: 2026-06-06
Released at: 2026-06-06 16:45 KST
Component: Web
Status: deployed

## Summary
공연 지도의 리스트 보기가 항상 현재 보이는 지도 화면 범위의 공연만 보여주도록 개선했습니다.

## Changes
- 공연 지도에서 "리스트로 보기"가 지금 보고 있는 지도 영역과 상관없이 전 세계 공연 전체를 보여주던 문제를 수정했습니다.
- 이제 리스트는 항상 현재 보이는 지도 화면 범위 안의 공연만 보여주어, 지도와 리스트가 동일한 영역을 기준으로 일관되게 표시됩니다.
- 리스트 화면으로 바로 들어가는 경우에도 내 위치를 기준으로 주변 공연이 자연스럽게 보이도록 개선했습니다.
- 지도와 리스트를 오가며 살펴볼 때 원하는 지역의 공연을 더 쉽게 확인할 수 있습니다.
- 위 변경 사항을 운영 환경에 배포하고 정상 동작을 확인했습니다.

## Known Issues
- 리스트를 처음 열 때 아주 짧은 순간 더 넓은 범위가 보였다가 현재 화면 범위로 정리될 수 있습니다.
