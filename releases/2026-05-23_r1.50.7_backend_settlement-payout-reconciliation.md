# r1.50.7 - Backend

Date: 2026-05-23
Released at: 2026-05-23 22:51 KST
Component: Backend
Status: deployed

## Summary
정산 화면과 관리자 정산 흐름에서 PayPal 지급과 결제 대사 흐름을 더 정확하게 확인할 수 있도록 보강했습니다.

## Changes
- 정산 화면의 원화 금액 표시를 통화 형식에 맞게 정리했습니다.
- 관리자 정산 화면에서 PayPal 수취 계정 입력과 지급 요청 흐름을 보강했습니다.
- PayPal 지급 상태와 결제 대사 결과가 정산 상태에 더 정확하게 반영되도록 서버 처리를 보강했습니다.
- Toss 원화 결제와 PayPal 해외 결제 정산 금액을 분리해서 확인할 수 있도록 정산 데이터 처리를 정리했습니다.

## Known Issues
- 이미 열린 앱 화면이나 PWA 캐시에서는 새 화면 번들이 바로 보이지 않을 수 있으므로 화면을 새로 열어야 합니다.
- 정산 금액은 로그인한 계정이 소유한 유료 티켓 주문과 완료된 정산 기록이 있을 때 표시됩니다.
