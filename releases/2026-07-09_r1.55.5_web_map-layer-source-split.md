# r1.55.5 - Web

Date: 2026-07-09
Component: Web
Status: deployed

## Summary
공연 지도의 상단 탭에서 '공연장'은 실제 등록된 공연장만, 'AI'는 AI로 수집한 공연장을 보여주도록 데이터 구분을 명확히 했습니다.

## Changes
- '공연장' 탭에서는 실제 등록·인증된 공연장만 지도에 표시되도록 했습니다.
- 'AI' 탭에서는 AI로 수집한 공연장이 빠짐없이 표시되도록 했습니다.
- 탭을 전환할 때 두 종류가 섞여 보이던 부분을 정리해 원하는 정보를 더 쉽게 찾을 수 있게 했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
