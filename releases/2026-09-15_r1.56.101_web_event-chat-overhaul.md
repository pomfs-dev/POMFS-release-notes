# r1.56.101 - Web

Date: 2026-09-15
Component: Web
Status: deployed

## Summary
공연 채팅을 더 쉽게 찾고 참여할 수 있도록 개편했습니다.

## Changes
- '전부' 탭이 공연별 대화 목록으로 바뀌어, 참여 여부와 상관없이 누구나 대화 내용을 둘러볼 수 있습니다(글쓰기는 참여자만 가능합니다).
- 아직 참여하지 않은 공연의 대화에는 참여를 안내하는 카드가 표시됩니다.
- 업계 탭과 랭크 채널에서 새 대화를 더 쉽게 시작할 수 있도록 진입 버튼과 이동 흐름을 정리했습니다.
- 채팅 공고 상세에 작성자 아바타와 이름, 포스터 이미지가 정확히 표시되도록 고쳤습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
