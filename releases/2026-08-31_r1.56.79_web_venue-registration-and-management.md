# r1.56.79 - Web

Date: 2026-08-31
Component: Web
Status: deployed

## Summary
공연장 사진 등록에 구도 조정을 추가하고, 신청·관리 과정에서 발생하던 입력 문제를 수정했습니다.

## Changes
- 공연장 사진 여러 장을 선택해도 등록되지 않던 문제를 수정했습니다.
- 공연장 신청과 관리 화면의 사진·대표 이미지 등록에 구도 조정 기능을 추가해 원하는 부분을 보이게 할 수 있습니다.
- '선택 항목'으로 안내되던 공연장 소개가 실제로는 필수였던 불일치를 바로잡고, 넓은 범위의 지도에서 화면을 확대하려 눌렀을 때 위치가 확정되던 문제를 수정했습니다.
- 운영 관리 화면에 위치 정보가 맞지 않는 공연장을 모아 확인하고 다시 정리할 수 있는 화면과, 심사·입점 진행 현황을 함께 볼 수 있는 정리를 추가했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
