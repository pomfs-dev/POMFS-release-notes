Date: 2026-09-15
Component: Web
Status: deployed

## Summary
아티스트 소개 화면의 디자인과 사용성을 개선했습니다.

## Changes
- 아티스트 소개 이미지가 화면 전체 너비로 표시되어 더 시원하게 보입니다.
- 섭외 문의를 작성할 때 키보드가 입력창을 가리지 않도록 개선했습니다.
- 공연장 정보, 포스터가 없을 때의 화면, 게시물 정보, 섭외 안내 문구 등 아티스트 페이지 곳곳의 표시를 더 보기 좋게 다듬었습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
