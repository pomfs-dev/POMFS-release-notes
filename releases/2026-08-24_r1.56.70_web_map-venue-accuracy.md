# r1.56.70 - Web

Date: 2026-08-24
Component: Web
Status: deployed

## Summary
공연장 지도 링크와 지도 화면, 공연장 상세 페이지의 표시 오류를 수정했습니다.

## Changes
- 일부 공연장의 구글 지도 링크가 엉뚱한 장소로 이동하던 문제를 수정했습니다.
- 주소 입력 화면의 작은 지도가 예전 모습으로 표시되고, 지도 글자가 계정에 설정한 언어와 다르게 나오던 문제를 수정했습니다.
- 지도에서 '오늘'로 걸어 둔 날짜 필터가 새로고침이나 뒤로 가기 후에 풀리던 문제를 수정했습니다.
- 공연장 상세의 대표 이미지가 흐릿하게 확대되어 보이던 문제와 소개글의 줄바꿈이 사라지던 문제를 수정했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
