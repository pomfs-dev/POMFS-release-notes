# r1.50.9 - Web

Date: 2026-05-28
Released at: 2026-05-28 04:28 KST
Component: Web
Status: deployed

## Summary
PayPal 결제 선택 흐름을 다시 활성화하고, 관리자 Payments 화면에서 정산 수수료를 직접 조정할 수 있게 했습니다.

## Changes
- PayPal 결제 서비스가 준비 중으로 표시되던 상태를 해소하고 결제 선택 흐름을 복구했습니다.
- 관리자 Payments 화면의 정산 수수료를 고정 문구가 아니라 정률과 정액 입력값으로 수정할 수 있게 했습니다.
- 저장된 수수료 설정이 정산 예정 금액 계산과 판매자 정산 요약에 반영되도록 서버 계산 흐름을 보강했습니다.
- 운영 배포 후 결제 화면, 관리자 API 접근 제어, 결제 관련 헬스 체크를 확인했습니다.

## Known Issues
- 이미 열려 있던 앱 세션이나 오래된 결제 화면은 앱을 완전히 종료한 뒤 새로 결제를 시작해야 최신 결제 설정을 사용할 수 있습니다.
- 국가와 PayPal 계정 정책에 따라 일부 PayPal 계정 간 결제는 PayPal 측에서 거절될 수 있으며, 국내 결제는 Toss Payments 사용을 권장합니다.
