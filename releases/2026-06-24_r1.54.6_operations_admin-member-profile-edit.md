# r1.54.6 - Operations

Date: 2026-06-24
Component: Operations
Status: deployed

## Summary
관리 도구에 회원 통합 프로필 편집 기능을 추가하고, 아티스트 소개와 SNS 정보 저장이 제대로 반영되도록 관리 기능을 개선했습니다. 운영자 전용 기능입니다.

## Changes
- 운영자가 회원의 여러 프로필 항목을 한 화면에서 통합적으로 편집할 수 있도록 관리 도구를 보강했습니다.
- 아티스트 소개 글과 SNS 링크 등 입력한 정보가 저장 후 정확히 반영되도록 다듬었습니다.
- 회원 관리 작업의 안정성을 높여 운영자가 더 일관되게 정보를 관리할 수 있게 했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
