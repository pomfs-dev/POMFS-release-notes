# r1.54.10 - Web

Date: 2026-06-25
Component: Web
Status: deployed

## Summary
게스트리스트 관리 화면을 입장 전과 입장 완료로 구분한 탭으로 개편해, 행사 현장에서 입장 현황을 더 빠르게 파악할 수 있도록 했습니다.

## Changes
- 게스트리스트 관리 화면을 입장 전과 입장 완료로 나눈 탭 구조로 정리했습니다.
- 아직 입장하지 않은 신청자와 이미 입장한 신청자를 한눈에 구분해 볼 수 있게 했습니다.
- 행사 현장에서 입장 처리 흐름을 더 직관적으로 따라갈 수 있도록 화면을 다듬었습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
