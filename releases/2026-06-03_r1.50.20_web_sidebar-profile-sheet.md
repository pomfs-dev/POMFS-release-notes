# r1.50.20 - Web

Date: 2026-06-03
Released at: 2026-06-03 07:50 KST
Component: Web
Status: deployed

## Summary
햄버거 메뉴 안의 프로필 사진을 눌러도 반응하지 않던 문제를 수정했습니다.

## Changes
- 햄버거 메뉴 프로필 카드의 프로필 사진을 클릭 가능한 항목으로 변경했습니다.
- 프로필 사진을 누르면 왼쪽 메뉴를 닫고 기존 프로필 바텀시트를 열도록 연결했습니다.
- 프로필 이미지가 없는 기본 이니셜 아바타도 동일하게 프로필 바텀시트를 열도록 정리했습니다.
- 운영 배포 후 실제 커뮤니티 웹 번들에서 메뉴 프로필 사진 클릭 시 프로필 바텀시트가 열리는지 확인했습니다.

## Known Issues
- 이미 열려 있던 앱 화면은 새로고침하거나 앱을 다시 열어야 최신 메뉴 동작이 반영될 수 있습니다.
