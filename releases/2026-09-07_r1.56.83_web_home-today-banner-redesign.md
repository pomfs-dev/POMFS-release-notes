## Summary
홈 화면 Today 배너와 채널 선택 디자인을 새로 정리하고 로딩 중 빈 화면을 없앴습니다.

## Changes
- 홈 Today 배너를 새 디자인으로 바꾸고 채널 선택 버튼을 라벨 형태로 정리했습니다.
- 유튜브 플레이어가 준비되기 전까지 배너가 검은 띠로 보이던 문제를 고쳐, 준비되는 동안에도 배너 이미지가 보이도록 했습니다.
- '새로운 공연' 카드의 포스터가 도착하기 전 빈 검은 사각형으로 보이던 문제를 로딩 표시로 대체했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
