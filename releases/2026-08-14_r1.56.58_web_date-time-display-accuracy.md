# r1.56.58 - Web

Date: 2026-08-14
Component: Web
Status: deployed

## Summary
앱 곳곳의 날짜와 시간 표시를 한국 시간 기준으로 정확하게 바로잡았습니다.

## Changes
- 공연 시간에 불필요한 초 단위가 표시되던 문제와 시간이 정해지지 않은 공연에 빈 시계 아이콘만 남던 문제를 수정했습니다.
- 일부 화면에서 날짜와 마감일이 하루 어긋나 표시되던 문제를 한국 시간 기준으로 바로잡았습니다.
- 당일 저녁 공연이 추천 목록에서 너무 일찍 사라지던 문제를 수정하고, 공연 정렬 시 같은 날짜 안에서도 시작 시간이 빠른 순서로 정렬되도록 했습니다.
- 한국어 설정에서 게시글 작성 시각만 영어로 표시되던 문제를 수정했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
