# r1.50.14 - Web

Date: 2026-05-28
Released at: 2026-05-28 05:00 KST
Component: Web
Status: deployed

## Summary
아티스트와 베뉴 회원가입 온보딩에서 국가에 따라 국내 계좌와 PayPal 정산 계정 연동을 안내하도록 확장했습니다.

## Changes
- 아티스트와 베뉴 신청 흐름에 PayPal 정산 계정 연동 카드를 추가했습니다.
- 한국 국가 선택 시 국내 계좌 입력을 유지하면서 PayPal 계정을 선택적으로 연결할 수 있게 했습니다.
- 한국 외 국가 선택 시 PayPal 계정 연동 중심의 정산 계좌 등록 흐름을 제공하도록 정리했습니다.
- PayPal 동의 화면 심사를 위해 글로벌 기본 영어 개인정보처리방침과 이용약관 페이지를 공개했습니다.
- 정산 계정 연동에서 PayPal 계정 식별과 확인 상태를 받을 수 있도록 Live OAuth 권한 요청을 정리했습니다.

## Known Issues
- PayPal Live 앱 리뷰가 승인되기 전까지 실제 PayPal 계정 연동은 PayPal 측에서 제한될 수 있습니다.
- PayPal의 국가별 계정 정책이나 계정 상태에 따라 일부 사용자는 계정 연동 또는 해외 정산 수령이 제한될 수 있습니다.
