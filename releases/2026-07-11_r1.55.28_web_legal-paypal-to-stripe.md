# r1.55.28 - Web

Date: 2026-07-11
Component: Web
Status: deployed

## Summary
이용약관·개인정보 처리방침에서 더 이상 사용하지 않는 PayPal 관련 문구를 정리하고, 결제·정산 안내를 현재 수단(토스·Stripe)에 맞게 갱신했습니다.

## Changes
- 약관의 결제·정산 섹션에서 PayPal 표기를 제거하고, 해외 카드 결제 제공자를 Stripe로 갱신했습니다.
- "PayPal 계정 연결" 조항을 "정산 계정 연결"로 일반화했습니다(해외 정산 수단 예: Stripe).
- 한국어·영문·일본어·스페인어·태국어 약관 제목/부제를 일관되게 반영했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
