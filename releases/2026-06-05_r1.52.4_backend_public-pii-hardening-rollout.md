# r1.52.4 - Backend

Date: 2026-06-05
Released at: 2026-06-05 20:10 KST
Component: Backend
Status: deployed

## Summary
공개 화면에 제공되는 정보가 꼭 필요한 항목만 포함되도록 개인정보 보호를 한층 더 확대했습니다.

## Changes
- 앞선 개인정보 보호 강화에 이어, 로그인하지 않아도 볼 수 있는 더 많은 공개 영역을 점검해 화면 표시에 필요한 항목만 제공되도록 정비했습니다.
- 공연과 공연장, 프로필, 피드, 알림 등 여러 공개 화면에 걸쳐 일관된 기준으로 정보 노출 범위를 정돈했습니다.
- 작성자 표시처럼 사용자가 보는 정보는 그대로 유지하면서, 계정과 관련된 민감한 세부 정보가 공개 응답에 불필요하게 포함되지 않도록 보강했습니다.
- 일부 공개 조회 화면에는 필요한 항목만 제공되도록 접근 범위를 추가로 정비했습니다.
- 변경 후에도 사용자가 보는 화면과 기능은 그대로 유지되도록 확인했습니다.
- 위 변경 사항을 운영 환경에 배포하고 정상 동작을 확인했습니다.

## Known Issues
- 공개 영역에 대한 추가 점검과 정비가 후속으로 진행될 수 있습니다.
