# r1.50.19 - Backend

Date: 2026-05-31
Released at: 2026-05-31 21:28 KST
Component: Backend
Status: deployed

## Summary
알림 목록과 푸시 알림이 사용자의 선택 언어 또는 기기 언어를 더 잘 따르도록 다국어 처리를 보강했습니다.

## Changes
- 새로 생성되는 알림과 푸시 문구가 사용자의 언어 설정을 기준으로 표시되도록 보강했습니다.
- 처음 접속하거나 앱을 사용할 때 기기 언어가 ko/en/ja/es/th 중 하나이면 기본 UI 언어로 자동 반영되도록 했습니다.
- iOS 앱의 푸시 등록 정보에도 기기 언어가 함께 전달되도록 소스를 준비했습니다.
- 로그인 후 언어 선택과 새 알림 언어가 더 일관되게 맞춰지도록 정리했습니다.

## Known Issues
- 이미 저장된 기존 알림 문구는 변경하지 않습니다.
- iOS 네이티브 소스 변경은 다음 iOS 앱 빌드/배포 이후 기기에 완전히 반영됩니다.
