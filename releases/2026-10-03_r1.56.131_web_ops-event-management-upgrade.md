# r1.56.131 - Web

Date: 2026-10-03
Component: Web
Status: deployed

## Summary
운영자용 공연 관리 화면에서 공연을 더 쉽게 찾고 상세 정보를 확인하며 포스터를 수정할 수 있게 되었습니다.

## Changes
- 공연 관리 목록에서 조건별 필터와 검색, 정렬을 사용할 수 있게 되었습니다.
- 검색 방법을 안내하는 문구를 추가하여 원하는 공연을 더 쉽게 찾을 수 있게 되었습니다.
- 공연 상세 화면에서 라인업, 티켓 정보, 수정 이력을 한눈에 확인할 수 있게 되었습니다.
- 공연 포스터를 상세 화면에서 직접 수정할 수 있게 되었습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
