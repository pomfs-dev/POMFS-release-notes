# r1.52.12 - Data Pipeline

Date: 2026-06-07
Released at: 2026-06-07 16:02 KST
Component: Data Pipeline
Status: deployed

## Summary
공연 지도에 잘못 수집되거나 잘못된 위치에 표시되던 항목을 정리하고, 앞으로 더 정확한 공연 정보만 노출되도록 데이터 품질을 개선했습니다.

## Changes
- 음악·공연과 관련 없는 항목이 공연으로 잘못 수집되어 공연 지도에 표시되던 것을 정리했습니다.
- 앞으로는 음악·공연 정보만 수집되도록 수집 기준을 강화해 비슷한 문제가 다시 생기지 않도록 했습니다.
- 한국 공연장이 같은 이름의 해외 장소로 잘못 표시되던 위치 문제를 바로잡고 재발을 방지했습니다.
- 일부 공연이 엉뚱한 공연장에 잘못 연결되어 표시되던 항목과, 오래전에 잘못 수집된 항목을 정리했습니다.
- 정리 후에도 정상적인 공연·공연장 정보는 그대로 유지되도록 확인했습니다.
- 위 변경 사항을 운영 환경에 배포하고 정상 동작을 확인했습니다.

## Known Issues
- 잘못 등록된 일부 한국 공연장의 위치는 순차적으로 수동 보정될 예정입니다.
