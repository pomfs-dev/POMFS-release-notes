# r1.56.85 - Web

Date: 2026-09-07
Component: Web
Status: deployed

## Summary
여러 화면의 문구, 아이콘, 배지 위치와 다크 테마 표시를 일관되게 다듬었습니다.

## Changes
- 등급 배지의 '운영진' 표기를 앱 표준인 '스태프'로 통일하고, 프로필 지표의 좋아요 아이콘을 하트로 바꾸었으며, 알림 설정의 저장 버튼을 프로필 설정과 같은 모양으로 맞췄습니다.
- 상단바의 읽지 않음 배지가 알림·메시지 아이콘을 가리던 위치와 검색 필터 배지 위치를 바로잡고, 아티스트 QR 카드 구분선이 다크 테마에서 흰색으로 튀던 문제와 티켓 배지 색 대비를 개선했습니다.
- 선호 장르 안내와 사이트맵 부제를 실제 동작에 맞게 정정하고, 공연 등록 방식 안내가 일본어·스페인어·태국어에서 영어로 나오던 문제와 초대·계정 삭제 안내가 단어 중간에서 줄바꿈되던 문제를 고쳤습니다.
- 지도에서 강조할 모임이 없는데도 공연 핀이 흐려지던 문제를 고치고 필터 영역을 정리했으며, 화면 스크롤바를 숨겨 더 깔끔하게 보이도록 했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
