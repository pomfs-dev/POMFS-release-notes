# r1.56.174 - Web

Date: 2026-10-24
Component: Web
Status: deployed

## Summary
서비스 예약 주문을 운영자가 환불할 수 있고, 예약 정보와 금액이 더 알아보기 쉽게 표시됩니다.

## Changes
- 운영자가 관리 화면에서 서비스 예약 주문을 직접 환불할 수 있으며, 결제 취소된 주문에는 안내 표시가 나타납니다.
- 관리자 주문 화면에서 영수증과 예약 정보를 확인할 수 있습니다.
- 예약형 서비스의 가격에 '/시간' 단위가 표시되고, '내 신청'에서 예약 금액과 환불 완료 여부를 볼 수 있습니다.
- 예약형 서비스에서는 불필요한 승인 버튼이 보이지 않으며, 판매를 다시 시작한 상품에서는 보관 표시가 사라집니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
