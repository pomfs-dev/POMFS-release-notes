# r1.54.8 - Web

Date: 2026-06-25
Component: Web
Status: deployed

## Summary
공연 지도와 목록에 표시되는 AI 수집 아티스트를 실제 아티스트 프로필 기반으로 개편했습니다. 핀이나 행을 누르면 해당 아티스트의 상세 정보와 공연 목록을 함께 볼 수 있습니다.

## Changes
- 공연 지도와 목록의 AI 수집 아티스트를 실제 아티스트 프로필 기반으로 다시 구성했습니다.
- 지도의 핀이나 목록의 행을 누르면 아티스트 상세 화면이 열리도록 했습니다.
- 아티스트 상세 화면에서 프로필 정보와 해당 아티스트의 공연 목록을 함께 볼 수 있게 했습니다.
- 아티스트 위치 표시가 더 정확하게 보이도록 정리했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
