# 3.0.2 - Android

Date: 2026-07-22
Component: Android
Status: deployed

## Summary
안드로이드 앱 첫 화면에서 구글 로그인이 실패하던 문제를 근본적으로 해결했습니다.

## Changes
- 안드로이드 앱이 구글 로그인 과정을 잘못 가로채던 근본 원인을 해소하여 첫 화면에서 로그인이 정상 완료되도록 수정했습니다.
- 구버전 앱을 사용하는 경우에도 로그인이 안정적으로 동작하도록 보완했습니다.
- 같은 로그인 요청이 중복으로 처리되어 실패하던 경우를 방지하도록 로그인 처리를 안정화했습니다.
- 수정된 안드로이드 앱 업데이트를 순차적으로 배포하고 있습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
