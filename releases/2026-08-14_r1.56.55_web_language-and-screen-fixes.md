# r1.56.55 - Web

Date: 2026-08-14
Component: Web
Status: deployed

## Summary
앱 언어 표시와 아티스트 전용 화면 등 여러 화면의 오류를 수정했습니다.

## Changes
- 앱 언어를 변경하면 이미 받은 알림도 새 언어로 표시되고, 기기 언어 때문에 앱 화면이 특정 언어로 고정되던 문제를 수정했습니다.
- '아티스트 전용' 화면에서 일부 메뉴가 열리지 않거나 '연결' 지표와 '내 네트워크' 목록이 항상 비어 보이던 문제, 프로필 기본 이미지가 깨져 보이던 문제를 바로잡았습니다.
- 더보기의 「함께 즐기기」 항목과 별도 지도 화면을 정리해 탐색 구조를 단순하게 만들었고, 앱 업데이트 직후 일부 화면이 열리지 않던 문제를 보완했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
