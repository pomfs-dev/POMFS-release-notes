# r1.56.20 - Web

Date: 2026-07-24
Component: Web
Status: deployed

## Summary
검색엔진이 MiSFY의 화면을 제대로 찾아갈 수 있도록 안내 정보 제공 방식을 바로잡았습니다.

## Changes
- 검색엔진에 전달되는 화면 안내 정보가 정상적으로 제공되지 않던 문제를 수정했습니다.
- 안내 목록에 실제로 존재하지 않는 화면이 포함되던 문제를 정정했습니다.
- 이에 따라 검색 결과에 노출되는 MiSFY 화면 정보의 정확도가 높아졌습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
