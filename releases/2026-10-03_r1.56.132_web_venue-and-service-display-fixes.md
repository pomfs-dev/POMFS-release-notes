# r1.56.132 - Web

Date: 2026-10-03
Component: Web
Status: deployed

## Summary
공연장 화면의 진입 속도를 개선하고 이름과 소개 문구가 잘못 표시되던 문제를 바로잡았습니다.

## Changes
- 공연장 화면에 들어갈 때 불필요한 정보를 한꺼번에 불러오던 동작을 줄여 더 빠르게 열리도록 개선했습니다.
- 공연장 이름이 같은 이름을 괄호로 반복해 표시되던 문제를 수정했습니다.
- 서비스 상세의 소개 항목에 요약 문구가 그대로 반복되던 문제를 수정하여 상세 소개가 표시되도록 했습니다.
- 이미지 업로드 시 로그인 여부를 확인하도록 보안을 강화했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
