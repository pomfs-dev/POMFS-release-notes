# r1.50.11 - Web

Date: 2026-05-28
Component: Web
Status: not-deployed

## Summary
공유하기 버튼과 공연 상세 링크가 더 안정적으로 동작하도록 개선했습니다.

## Changes
- 공연 상세 공유 문구와 링크가 붙어서 잘못된 주소로 인식되는 문제를 방지했습니다.
- 공유받은 공연 상세 링크를 직접 열 때 데이터 확인 전 404 화면으로 이동하지 않도록 개선했습니다.
- 피드, 공연장, 티켓, 아티스트 드롭, 프로필, 토론, 이벤트 채팅, 콜라보 프로젝트 등 여러 화면의 공유 버튼 동작을 정리했습니다.
- 네이티브 공유를 사용할 수 없는 환경에서는 전체 공유 문구와 링크를 클립보드로 복사하도록 보강했습니다.

## Known Issues
- 이 변경사항은 다음 웹 배포에 포함되어야 실제 사용자에게 적용됩니다.
