# r1.56.78 - Web

Date: 2026-08-31
Component: Web
Status: deployed

## Summary
아티스트 탐색에 정렬·필터를 더하고, 프로필과 활동 지표가 실제 데이터를 보여주도록 개선했습니다.

## Changes
- 아티스트 목록에 점수 기준 정렬과 장르·국가별 보기를 추가했습니다.
- 아티스트 활동 분석 화면이 예시 값 대신 실제 활동 내용을 보여주도록 수정하고, 상단의 빈 지표와 동작하지 않던 영역을 정리했습니다.
- 프로필의 게시물 탭에서 첨부한 영상이 표시되지 않고 글 상세로 이동할 수 없던 문제를 수정했습니다.
- 프로필 설정의 국가 표시가 잘못 고정되던 문제, 국가 표기 방식, 닉네임 글자 수 안내(20자)를 실제 기준에 맞게 통일하고 어두운 화면에서의 카드 표시를 다듬었습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
