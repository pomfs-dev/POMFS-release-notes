# r1.56.138 - Web

Date: 2026-10-06
Component: Web
Status: deployed

## Summary
결제·정산·지급 기록이 있는 계정은 탈퇴할 때 기록을 지우지 않고 개인 식별 정보만 익명 처리하도록 개선했습니다.

## Changes
- 결제, 정산 또는 지급 기록이 있는 계정이 탈퇴하면 계정을 완전히 삭제하지 않고 개인 식별 정보를 익명으로 바꿔 처리합니다.
- 계정 삭제는 어떤 경로로 진행하더라도 동일한 기준이 적용됩니다.
- 탈퇴 후에도 과거 결제·정산·지급 내역이 보존되어 정산 확인과 문의 대응이 정확해집니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
