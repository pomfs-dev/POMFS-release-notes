# r1.54.1 - Web

Date: 2026-06-21
Component: Web
Status: deployed

## Summary
아티스트 음악 링크에 외부 열기 버튼을 추가하고 입력 오류 메시지를 다국어로 제공하는 등 음악 링크의 표시와 저장 경험을 개선했습니다.

## Changes
- 아티스트 음악 링크를 외부 음악 앱이나 브라우저에서 바로 열 수 있는 버튼을 추가했습니다.
- 음악 링크 입력 시 형식이 올바르지 않을 경우 사용 중인 언어에 맞춰 오류 메시지를 보여주도록 했습니다.
- 음악 링크의 표시와 저장 과정을 다듬어 더 안정적으로 처리되도록 개선했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
