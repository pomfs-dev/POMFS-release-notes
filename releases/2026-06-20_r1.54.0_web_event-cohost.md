# r1.54.0 - Web

Date: 2026-06-20
Component: Web
Status: deployed

## Summary
공연에 공동 주최자를 초대해 함께 관리할 수 있는 기능을 추가했습니다.

## Changes
- 공연을 등록한 분이 다른 회원을 공동 주최자로 초대할 수 있습니다.
- 공동 주최자로 초대되면 알림을 받고, 공연 정보를 함께 편집할 수 있습니다.
- 공동 주최자도 입장 스캐너에서 해당 공연의 게스트 입장을 처리할 수 있습니다.
- 공연 삭제와 공동 주최자 추가·삭제는 공연을 등록한 분만 할 수 있도록 했습니다.
- 변경 사항이 배포되었습니다.
