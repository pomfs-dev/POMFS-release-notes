# r1.52.0 - Operations

Date: 2026-06-05
Released at: 2026-06-05 01:45 KST
Component: Operations
Status: deployed

## Summary
공연·공연장 정보가 매일 자동으로 수집·정리되어 더 많은 공연장과 한국 공연이 앱에 노출됩니다.

## Changes
- 매일 정해진 시각에 공연장과 아티스트 정보를 자동으로 수집하고, 분류와 정합(중복 제외)까지 한 번에 처리하도록 자동화했습니다.
- 한국 공식 공연 데이터의 공연장과 공연을 자동으로 가져와 앱에 올릴 대상에 포함했습니다.
- 발행 단계에서 이미 앱에 등록된 항목은 중복으로 자동 제외해 별도로 분류하고, 수집·분류 과정의 중복 항목도 자동으로 정리되도록 했습니다.
- 그 결과 더 많은 공연장과 한국 공연이 앱에서 보이게 되었습니다.
- 데이터 수집 공급원을 하나로 일원화하고, 해외 위치 정보 처리도 표준 방식으로 통일했습니다.
- 위 변경 사항을 실제 서비스에 배포하고 정상 동작을 확인했습니다.
