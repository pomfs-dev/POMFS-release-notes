# r1.56.84 - Web

Date: 2026-09-07
Component: Web
Status: deployed

## Summary
실제 상태와 다르게 보이던 화면과 돌아갈 방법이 없던 화면들을 바로잡았습니다.

## Changes
- 주문 없이 열린 결제 완료 화면이 '결제 완료'와 축하 효과를 보여주던 문제, 이메일 인증 화면이 보내지 않은 메일을 발송했다고 안내하던 문제를 고쳤습니다.
- 없거나 권한이 없는 그룹 채팅방이 빈 방으로 열리던 문제, 마감된 협업 프로젝트의 지원 버튼이 눌리며 '이미 지원함'으로 잘못 안내되던 문제, 함께 즐기기 초대 알림이 활동 탭이 아닌 곳에 들어가던 문제를 바로잡았습니다.
- 링크로 연 '내 글' 화면이 탐색 화면으로 튕기거나 첨부된 영상·이미지가 보이지 않던 문제를 고치고, 내 글 화면과 공연장 관리 화면에 뒤로가기 버튼을 추가했습니다.
- 검색 결과 공연 줄에 작성자 닉네임이 빠지던 문제와 리뷰·네트워크가 불러오는 중에 '결과 없음'으로 보이던 문제를 고쳤고, 정산 화면에 수수료 공제·보류 내역을 표시하고 정산 계정 연결을 마친 뒤 앱으로 바로 돌아오도록 했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
