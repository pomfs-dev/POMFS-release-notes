# r1.56.102 - Web

Date: 2026-09-15
Component: Web
Status: deployed

## Summary
티켓 판매와 취소·환불 과정의 안전장치를 강화했습니다.

## Changes
- 정산 계좌 확인이 끝나지 않은 주최자는 티켓 판매를 시작할 수 없도록 안전장치를 강화했습니다. 판매가 제한된 경우 그 사유를 화면에 정확히 안내합니다.
- 주최자가 공연을 취소할 때 사유를 반드시 남기도록 했고, 구매자는 결제 금액을 100% 환불받으며 환불 결과를 화면에서 바로 확인할 수 있습니다.
- 정산 화면을 통화별로 한 장의 카드로 정리하고, 결제 방식이 판매자 기준 통화에 맞게 정확히 표시되도록 고쳤습니다.
- 공연 입장 시 유효한 티켓이 '유효하지 않음'으로 잘못 인식되던 오류를 고쳤습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
