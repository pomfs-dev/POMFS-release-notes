Date: 2026-06-03

## Summary
검색 결과에서 이벤트를 선택해도 상세 화면으로 이동하지 않던 문제를 수정했습니다.

## Changes
- 검색 결과의 이벤트 항목을 누르면 해당 이벤트 상세 화면으로 이동하도록 수정했습니다.
- 공연장 기반 이벤트와 아티스트가 만든 이벤트의 상세 링크를 구분해 처리하도록 보강했습니다.
- 다가오는 공연 영역에서도 이벤트 상세로 먼저 이동하고, 상세 링크를 만들 수 없는 경우에만 공연장 화면으로 이동하도록 정리했습니다.
- 운영 배포 후 실제 커뮤니티 웹 번들에서 검색 이벤트 선택 동작을 확인했습니다.

## Known Issues
- 이미 열린 앱 화면은 새로고침하거나 앱을 다시 열어야 최신 검색 동작이 반영될 수 있습니다.
