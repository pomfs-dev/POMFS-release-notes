# r1.56.22 - Web

Date: 2026-08-03
Component: Web
Status: deployed

## Summary
아티스트·공연장 등급을 유료 상품 없이 무료 신청과 승인으로 받도록 절차를 정비했습니다.

## Changes
- 아티스트·공연장 유료 등급 상품을 없애고, 무료로 신청한 뒤 승인받는 방식으로 일원화했습니다.
- 등급 신청 화면에 프로필 사진 등록 안내를 추가하여, 사진을 갖춘 상태로 신청하실 수 있도록 했습니다.
- 기존 등급 안내 화면으로 접속하시면 현재 등급 현황 화면으로 자동 이동합니다.
- 등급 신청과 승인 과정의 보안을 강화했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
