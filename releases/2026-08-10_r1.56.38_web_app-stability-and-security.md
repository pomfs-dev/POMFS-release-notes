# r1.56.38 - Web

Date: 2026-08-10
Component: Web
Status: deployed

## Summary
앱 실행과 저장 과정에서 발생하던 오류를 해결하고 보안을 강화했습니다.

## Changes
- 앱이 시작 화면에서 멈추거나 새로고침이 반복되던 문제를 해결하고, 간헐적으로 발생하던 접속 오류를 줄였습니다.
- 버그 신고와 기능 제안, 새 프로젝트 만들기, 내 프로젝트 등록, 공연장 대표 이미지 올리기가 실제로는 전송되지 않았는데 성공처럼 보이던 문제를 수정했습니다. 삭제·수정이 실패했을 때도 성공으로 표시되지 않습니다.
- 토론 목록에서 작성자 이름이 비어 있거나 추천 수가 잘못 표시되던 문제, 홈 화면 일부 영역이 검은 여백으로 남던 문제, 내 프로젝트의 남은 일수가 비정상적으로 크게 표시되던 문제, 즐겨찾기 목록에서 좋아요 표시가 반영되지 않던 문제를 수정했습니다.
- 점검 종료 예정 시각이 지난 날짜로 안내되던 문제를 바로잡고, 계정 보호를 위해 보안을 강화했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
