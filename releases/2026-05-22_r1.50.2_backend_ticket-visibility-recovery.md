# r1.50.2 - Backend

Date: 2026-05-22
Released at: 2026-05-22 10:12 KST
Component: Backend
Status: deployed

## Summary
실제 승인된 티켓 결제가 나의 티켓에 표시되도록 결제 확정과 티켓 조회 흐름을 보강했습니다.

## Changes
- 결제 확정 중 일부 보조 처리 실패가 전체 티켓 발급을 막지 않도록 서버 처리 흐름을 보강했습니다.
- 실제 승인 완료된 주문이 결제 완료 상태와 발급 티켓으로 정리되도록 복구 절차를 적용했습니다.
- 나의 티켓 화면에서 결제 서버에 발급된 티켓도 함께 확인할 수 있도록 조회 흐름을 개선했습니다.
- 결제 완료와 티켓 발급 상태가 서로 어긋나 보이는 사례를 줄이도록 결과 데이터를 정리했습니다.

## Known Issues
- 이미 열린 앱 화면은 이전 캐시를 볼 수 있으므로 앱을 다시 열거나 화면을 다시 진입해야 최신 티켓 상태가 보일 수 있습니다.
