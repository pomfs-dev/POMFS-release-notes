# r1.56.94 - Web

Date: 2026-09-15
Component: Web
Status: deployed

## Summary
홈 화면 상단과 탐색 화면을 새롭게 단장했습니다.

## Changes
- 홈 화면 상단의 바로가기 버튼을 소식을 볼 수 있는 배너로 교체했습니다.
- 메뉴 서랍 상단에 자주 쓰는 기능으로 바로 가는 아이콘을 추가했습니다.
- 탐색 화면의 추천 카드를 더 크게 키웠습니다.
- 관리자가 공지를 등록하면 전체 사용자에게 알림이 전송되고, 알림을 누르면 해당 공지로 바로 이동합니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
