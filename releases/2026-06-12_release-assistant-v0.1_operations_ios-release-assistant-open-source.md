# release-assistant-v0.1 - Operations

Date: 2026-06-12
Component: Operations
Status: deployed

## Summary
iOS 앱 출시 준비를 단계별로 도와주는 iOS Release Assistant를 오픈소스 도구로 정리하고, 초보자도 따라갈 수 있도록 문서를 보강했습니다.

## Changes
- App Store 출시 준비에 필요한 앱 정보, Apple 기능, 심사 정보, Xcode 프로젝트 생성 흐름을 단계별로 안내하도록 정리했습니다.
- App Store Connect API Key 연결, one-time approval, local bridge 기반의 민감정보 비저장 흐름을 문서화했습니다.
- README를 한국어 우선과 영어 섹션으로 구성하고, 준비물과 Review & Confirm 사용 순서를 추가했습니다.
- 미리보기 이미지를 공개용 샘플 값으로 정리해 README 상단에 배치했습니다.
- 업로드하면 안 되는 키, 인증서, 빌드 산출물, 로컬 백업 파일은 저장소 ignore와 별도 기여 안내로 분리했습니다.
