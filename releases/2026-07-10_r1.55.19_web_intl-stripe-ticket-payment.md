# r1.55.19 - Web

Date: 2026-07-10
Component: Web
Status: deployed

## Summary
해외 공연 티켓을 현지 통화로 Stripe 카드 결제할 수 있게 했습니다.

## Changes
- 해외 공연 티켓 주문 시 태국 바트 등 12개 통화를 추가로 지원합니다.
- 해외 공연 결제에 Stripe 카드 결제를 연결했습니다. 국내 공연은 기존과 동일하게 토스 결제를 사용합니다.
- 결제 금액과 통화를 서버에 저장된 값 기준으로 검증해 잘못된 금액 청구를 방지합니다.
- 결제 완료 후 티켓 발급 확인 화면이 해외 결제 결과를 정확히 반영하도록 연결했습니다.
- 해외 결제 건의 환불과 정산 처리도 함께 지원합니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
