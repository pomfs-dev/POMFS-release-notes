# r1.56.103 - Web

Date: 2026-09-15
Component: Web
Status: deployed

## Summary
프로필과 피드 등 여러 화면을 다듬었습니다.

## Changes
- 프로필 커버 사진을 최대 10장까지 등록할 수 있습니다.
- 홈 화면의 새 멤버 카드 디자인을 정비해 장르와 합류 시점을 더 보기 좋게 표시합니다.
- 피드 상단의 여러 탭을 하나의 탐색 화면으로 단순화했습니다.
- 프랑스어를 사용하는 계정의 알림·메일·피드 언어가 한국어로 바뀌어 보이던 문제를 고치고, 프랑스어 지원을 추가했습니다. 업계 탭과 공연장 화면의 세부 표시, 이전 구독 등급 관련 안내 문구도 함께 정리했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
