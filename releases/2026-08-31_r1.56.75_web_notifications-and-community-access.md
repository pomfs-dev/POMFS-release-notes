# r1.56.75 - Web

Date: 2026-08-31
Component: Web
Status: deployed

## Summary
알림과 커뮤니티 글을 지난 항목까지 모두 확인할 수 있게 하고, 참여 과정에서 발생하던 문제들을 수정했습니다.

## Changes
- 알림함과 토론·콜라보 목록에서 최근 항목만 보이고 그 이전 내용을 열 수 없던 문제를 수정했으며, 공지의 강조 표시가 정상적으로 나타나도록 했습니다.
- 알림 수신이 조용히 끊겨 있던 경우 자동으로 다시 연결되도록 개선했습니다.
- 콜라보 지원하기가 아무 반응 없이 접수되지 않던 문제와, 초대 링크 복사가 열리지 않는 주소를 만들던 문제를 수정했습니다.
- 글 공유 버튼이 다른 버튼에 가려 눌리지 않던 문제와, 하단 메뉴가 없는 화면에서 안내 띠가 본문을 가리던 문제를 수정했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
