# r1.56.80 - Web

Date: 2026-09-07
Component: Web
Status: deployed

## Summary
가입 아티스트 랭킹을 MiSFY Score 하나로 통일하고, 점수 기준 안내와 성장 진단을 새로 제공합니다.

## Changes
- 아티스트 랭킹을 MiSFY Score 기준 하나로 통일하고, 별도의 새 멤버 탭 대신 각 아티스트 옆에 점수와 NEW·라이징 표시를 함께 보여드립니다.
- '평가 기준' 버튼을 누르면 MiSFY Score 산정 방식을 안내 창에서 확인할 수 있고, 점수가 아직 집계 중인 아티스트는 그 상태가 표시되며, 성장 진단 안내로 어떤 활동이 도움이 되는지 살펴볼 수 있습니다.
- 높은 점수의 라이징 아티스트는 프로필 사진에 장르 색상 테두리와 배지 강조가 적용되고, 검색의 인기 아티스트 정렬 기준도 화면에 함께 표시됩니다.
- 장르 필터를 아티스트·공연·피드 화면에서 같은 라벨 형태로 통일했고, 랭킹 줄의 구독자 수와 배지가 잘리거나 어색하게 줄바꿈되던 문제와 데스크톱에서 인스타그램 프로필이 열리지 않던 문제를 고쳤습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
