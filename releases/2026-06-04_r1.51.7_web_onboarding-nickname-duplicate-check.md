Date: 2026-06-04

Component: Web
Status: deployed

## Summary
가입 온보딩에서 이미 사용 중인 닉네임을 고르면 곧바로 알려주고 막아줍니다.

## Changes
- 가입 시 닉네임을 정하는 단계에서 이미 다른 사람이 쓰고 있는 닉네임을 입력하면 중복 안내 메시지가 뜨고 다음으로 넘어가지 않도록 했습니다.
- 중복 안내 문구를 여러 언어로 제공해, 사용하는 언어에 맞춰 표시됩니다.
- 닉네임 검사는 대소문자를 구분하지 않아, 같은 글자라면 대문자/소문자가 달라도 중복으로 처리됩니다.
- 본인을 제외한 모든 계정을 기준으로 검사해, 다른 사용자가 이미 쓰는 닉네임은 선택할 수 없습니다.
- 변경 사항은 배포되어 정상 동작을 확인했습니다.
