# r1.55.13 - Web

Date: 2026-07-09
Component: Web
Status: deployed

## Summary
함께 즐기기를 별도 화면 이동 없이 공연 지도 위에서 바로 시작할 수 있습니다.

## Changes
- 지도에서 '함께 즐기기'를 누르면 화면 이동 없이 모임 만들기 폼이 바로 열립니다.
- 공연 상세에서 '이 공연으로 함께 즐기기'를 누르면 해당 공연이 자동 선택됩니다.
- 모임 위치 핀이 공연 지도 위에 함께 표시됩니다.
- 모임 만들기 버튼 색을 브랜드 그린으로 통일했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
