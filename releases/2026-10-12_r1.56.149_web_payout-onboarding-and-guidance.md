# r1.56.149 - Web

Date: 2026-10-12
Component: Web
Status: deployed

## Summary
정산 계정 등록 링크를 발급받아 중단된 등록을 이어서 진행할 수 있게 했습니다.

## Changes
- 정산 계정 등록용 링크를 발급받아 직접 등록을 진행할 수 있게 했습니다.
- 등록을 중간에 멈춘 경우 처음부터 다시 하지 않고 이어서 진행할 수 있게 했습니다.
- 정산을 지원하지 않는 지역과 제재 대상 국가는 '준비 중'과 구분해 안내하도록 했습니다.
- 전액 환불 또는 취소된 건의 정산 대기 상태가 올바르게 정리되도록 개선했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
