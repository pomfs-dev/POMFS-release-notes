# r1.56.56 - Web

Date: 2026-08-14
Component: Web
Status: deployed

## Summary
서비스 스토어의 신청 과정을 개편하고 표시 오류를 정리했습니다.

## Changes
- 서비스 신청 시 음원 링크, 상세 설명, 희망 일정을 함께 입력할 수 있도록 신청 양식을 개편했습니다.
- 신청이 접수되면 담당자에게 즉시 알림이 전달되어 확인이 빨라졌습니다.
- 협업 화면에서 관련 서비스를 안내하는 배너를 추가하고, 가격이 확정되지 않은 서비스의 가격 표시를 정리했습니다.
- 서비스 이미지가 없을 때 깨진 이미지가 표시되던 문제와 준비되지 않은 평점 표시를 정리했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
