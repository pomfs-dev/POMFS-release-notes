# r1.56.182 - Web

Date: 2026-10-25
Component: Web
Status: deployed

## Summary
정산 시작 안내와 환불 상태 표시를 더 정확하게 다듬었습니다.

## Changes
- 정산을 지원하지 않는 지역과 준비 중인 지역을 구분해 안내하도록 했습니다.
- 정산 계정 등록을 중간에 멈춰도 이어서 진행할 수 있게 했습니다.
- 티켓 판매가 불가능한 판매자가 정산 가능으로 표시되던 문제를 바로잡았습니다.
- 전액 환불·취소된 건이 정산 대기 상태로 남지 않도록 처리했습니다.
- 서비스 주문이 환불되면 연결된 신청도 환불 상태로 표시하고, 관리자 신청 목록에서도 확인할 수 있게 했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
