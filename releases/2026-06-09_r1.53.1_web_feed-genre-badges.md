# r1.53.1 - Web

Date: 2026-06-09
Component: Web
Status: deployed

## Summary
Feed 카드에서 일반 AI 표시 대신 공연과 콘텐츠의 장르를 더 분명하게 볼 수 있도록 장르 뱃지를 표시했습니다.

## Changes
- Feed 카드 상단의 표시 방식을 정리해, 사용자가 콘텐츠 성격을 더 빨리 파악할 수 있게 했습니다.
- 유효한 장르가 있는 경우 장르 뱃지를 보여주고, 불필요한 일반 AI 표시는 숨기도록 다듬었습니다.
- 공유 장르 뱃지 컴포넌트를 정리해 여러 피드 카드에서 일관된 표시를 사용할 수 있게 했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
