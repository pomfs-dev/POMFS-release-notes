# r1.56.12 - Web

Date: 2026-07-23
Component: Web
Status: deployed

## Summary
채팅에서 내가 보낸 메시지를 밀어서 수정할 수 있는 기능을 추가했습니다.

## Changes
- 내가 보낸 채팅 메시지를 옆으로 밀어 수정 버튼을 눌러 바로 고칠 수 있습니다.
- 수정된 메시지에는 '수정됨' 표시가 붙어 다른 참여자도 변경 여부를 알 수 있습니다.
- 수정한 내용은 같은 채팅방의 다른 참여자 화면에 실시간으로 반영됩니다.
- DM, 이벤트 채팅 등 모든 채팅 화면에서 동일하게 사용할 수 있으며, 본인이 보낸 메시지만 수정할 수 있습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
