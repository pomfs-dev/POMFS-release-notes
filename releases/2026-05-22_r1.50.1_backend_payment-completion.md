# r1.50.1 - Backend

Date: 2026-05-22
Released at: 2026-05-22 03:20 KST
Component: Backend
Status: deployed

## Summary
티켓 결제가 실제 승인 후 구매 완료와 티켓 발급으로 이어지도록 결제 완료 흐름을 개선했습니다.

## Changes
- Toss 결제 앱에서 돌아온 뒤 실제 결제 확정 API를 호출하도록 수정했습니다.
- 결제 확정에 실패했을 때 완료 화면과 실패 안내가 함께 보이지 않도록 결과 화면을 정리했습니다.
- 티켓을 여러 장 구매하면 구매한 수량만큼 티켓이 발급되도록 서버 발급 흐름을 개선했습니다.
- PayPal 결제도 주문 통화와 실제 청구 통화를 분리해 기록하도록 정리했습니다.
- 결제 웹훅은 결제 제공사의 조회 결과를 다시 확인한 뒤 완료 처리하도록 보강했습니다.

## Known Issues
- PayPal은 계정/국가/카드 정책에 따라 결제 제공사 화면에서 거절될 수 있습니다.
