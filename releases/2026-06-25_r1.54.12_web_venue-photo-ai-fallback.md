# r1.54.12 - Web

Date: 2026-06-25
Component: Web
Status: deployed

## Summary
공연장 사진이 없을 때 빈 화면 대신 AI 포스터나 아바타 이미지로 자연스럽게 대체 표시되도록 해, 어떤 공연장이든 보기 좋은 화면을 보여줍니다.

## Changes
- 공연장 사진이 등록되어 있지 않을 때 빈 자리나 깨진 이미지 대신 AI 포스터 또는 아바타 이미지를 보여주도록 했습니다.
- 사진이 있는 공연장과 없는 공연장이 화면에서 일관된 모습으로 보이도록 다듬었습니다.
- 공연 카드와 공연장 화면 전반에서 더 자연스러운 이미지 표시를 제공합니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
