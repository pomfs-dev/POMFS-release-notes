# r1.56.62 - Web

Date: 2026-08-17
Component: Web
Status: deployed

## Summary
어느 지역·시간대에서 접속해도 공연 날짜와 '다가오는 공연' 목록이 정확하게 표시되도록 개선했습니다.

## Changes
- 해외(미주 등) 시간대에서 공연 날짜가 실제보다 하루 이르게 보이거나, 당일 저녁 공연이 목록에서 일찍 사라지던 문제를 수정했습니다.
- '다가오는 공연' 목록이 한국 시간 기준으로 일관되게 계산되도록 통일하고, 이미 시작한 공연이 목록 상단에 나타나던 문제를 수정했습니다.
- '다가오는 공연' 목록에 공연장 이름이 표시되지 않던 문제를 수정했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
