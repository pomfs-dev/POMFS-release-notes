# r1.50.10 - Web

Date: 2026-05-28
Component: Web
Status: not-deployed

## Summary
기존 이메일 계정의 로그인 입력 검증과 비밀번호 재설정 진입 흐름을 보강했습니다.

## Changes
- 로그인 화면에서는 비밀번호가 비어 있는지만 확인하고, 실제 비밀번호 검증은 서버가 처리하도록 조정했습니다.
- 회원가입 화면의 현재 비밀번호 정책은 그대로 유지해 신규 계정 보안 기준은 낮추지 않았습니다.
- 비밀번호 재설정 코드 요청과 코드 확인 경로가 인증 프록시를 통해 정상 전달되도록 보강했습니다.
- 관련 입력 검증과 인증 프록시 경로 테스트를 추가했습니다.

## Known Issues
- 이 변경사항은 다음 웹 배포에 포함되어야 실제 사용자에게 적용됩니다.
