Date: 2026-07-24
Component: Web
Status: deployed

## Summary
티켓 구매 시 주문이 생성되지 않아 결제를 진행할 수 없던 문제를 수정했습니다.

## Changes
- 티켓 주문 단계에서 '주문 생성 실패' 안내가 표시되며 결제가 중단되던 문제를 해결했습니다.
- 공연이 열리는 지역을 기준으로 결제 통화를 올바르게 판단하도록 개선했습니다.
- 국내 공연은 원화로 안정적으로 결제되도록 기본 처리를 보완했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
