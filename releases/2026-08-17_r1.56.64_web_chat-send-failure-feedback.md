# r1.56.64 - Web

Date: 2026-08-17
Component: Web
Status: deployed

## Summary
채팅 메시지 전송에 실패했을 때 아무 안내 없이 입력한 내용이 사라지던 문제를 수정했습니다.

## Changes
- 메시지 전송에 실패해도 아무 안내가 없고 입력한 내용까지 사라지던 문제를 수정했습니다.
- 이제 전송에 실패하면 실패했다는 안내가 표시되고, 작성한 내용은 그대로 유지되어 다시 보낼 수 있습니다.
- 개인 메시지와 공연·등급 채팅방 모두에 동일하게 적용됩니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
