# r1.50.5 - iOS

Date: 2026-05-22
Released at: 2026-05-22 22:46 KST
Component: iOS
Status: deployed

## Summary
iOS 앱에서 티켓 메일의 앱 열기 버튼이 티켓 화면으로 이어질 수 있도록 딥링크 처리를 보강했습니다.

## Changes
- iOS 앱이 POMFS 전용 앱 열기 링크를 받을 수 있도록 URL scheme을 추가했습니다.
- 앱이 이미 켜져 있을 때 티켓 링크를 누르면 웹뷰 안에서 해당 티켓 경로로 이동하도록 딥링크 처리를 보강했습니다.
- 웹뷰가 아직 준비되지 않은 상태에서 들어온 링크는 로딩 완료 후 처리하도록 안정성을 높였습니다.

## Known Issues
- 이 변경은 iOS 앱 소스 변경이므로 실제 사용자는 새 앱 빌드 설치 후 확인해야 합니다.
- 현재 작업 환경에는 전체 Xcode가 없어 로컬 아카이브 빌드는 수행하지 못했습니다.
