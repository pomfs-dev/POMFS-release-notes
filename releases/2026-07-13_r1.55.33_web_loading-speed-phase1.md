# r1.55.33 - Web

Date: 2026-07-13
Component: Web
Status: deployed

## Summary
앱 첫 화면이 뜨는 속도를 크게 개선하고, 공연장 목록과 채팅의 데이터 처리를 가볍게 다듬었습니다.

## Changes
- 글꼴 로딩 방식을 개선하여 첫 화면이 표시되기까지 걸리는 시간을 크게 줄였습니다.
- 앱이 준비되는 동안 시작 화면을 보여주어 빈 화면 없이 자연스럽게 진입하도록 했습니다.
- 공연장 목록을 경량화된 방식으로 불러오도록 바꿔 목록이 훨씬 빠르게 열립니다.
- 채팅 읽음 처리 과정에서 불필요한 저장 동작을 없애고 대용량 대화 처리도 개선했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
