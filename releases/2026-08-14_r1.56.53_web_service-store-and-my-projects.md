# r1.56.53 - Web

Date: 2026-08-14
Component: Web
Status: deployed

## Summary
서비스 스토어의 신청 과정이 정상 동작하도록 완성되고, 내 프로젝트·공지 관련 편의 기능이 더해졌습니다.

## Changes
- 서비스 스토어에서 신청서 제출이 실패하던 문제를 해결하고, 신청부터 검토까지 전 과정이 정상적으로 진행되도록 완성했습니다.
- 서비스 상세 화면에 제공자 정보가 표시되며, 실제 작성되지 않은 예시 후기는 제거했습니다.
- 더보기 메뉴에 '내 프로젝트'와 '내 서비스 신청' 진입점을 추가했고, '내 프로젝트' 화면이 항상 비어 보이던 문제를 수정했으며, 프로젝트 마감일이 올해가 아니면 연도까지 함께 표시됩니다.
- 공지사항을 즐겨찾기해 두고 다시 찾아볼 수 있습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
