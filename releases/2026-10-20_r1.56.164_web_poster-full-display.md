# r1.56.164 - Web

Date: 2026-10-20
Component: Web
Status: deployed

## Summary
공연 포스터가 잘리지 않고 원본 모습 그대로 보이도록 개선했습니다.

## Changes
- 공연 상세 화면에서 포스터가 잘리지 않고 세로형 비율로 전체가 표시됩니다.
- 홈의 공연 카드와 프로필의 공연 썸네일에서도 포스터가 같은 방식으로 표시됩니다.
- 홈의 '새로운 공연' 카드는 아티스트나 가격 정보가 없어도 카드 높이가 일정하게 유지되어 화면이 흔들리지 않습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
