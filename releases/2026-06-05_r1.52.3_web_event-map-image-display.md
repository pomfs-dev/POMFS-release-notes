Date: 2026-06-05
Released at: 2026-06-05 12:47 KST
Component: Web
Status: deployed

## Summary
공연 지도의 리스트 보기에서 일부 공연 항목의 이미지가 깨져 보이던 문제를 개선해, 깔끔한 이미지로 표시되도록 했습니다.

## Changes
- 공연 지도의 리스트 보기에서 일부 공연 항목의 이미지가 깨진 모양으로 보이던 문제를 해결했습니다.
- 표시할 이미지가 없는 경우에는 깨진 아이콘 대신 깔끔한 음표 모양의 기본 이미지가 표시되도록 했습니다.
- 가능한 경우 공연 포스터 이미지를 더 잘 표시하도록 개선했습니다.
- 이미지가 정상적으로 표시되던 항목은 그대로 유지되도록 했습니다.
- 위 변경 사항을 운영 환경에 배포하고 정상 동작을 확인했습니다.

## Known Issues
- 일부 공연은 표시할 포스터 이미지가 없어 기본 플레이스홀더로 표시될 수 있습니다.
