Date: 2026-06-04

Component: Web
Status: deployed

## Summary
공연 지도의 리스트 보기에서 공연이 더 직관적인 순서로 정렬되도록 개선했습니다.

## Changes
- 공연 지도 리스트 보기의 정렬을 네 가지 분류 순서로 새롭게 재배치했습니다.
- 가장 먼저 실제 아티스트가 올린 공연이 보입니다.
- 그다음으로 실제 공연장의 공연이 표시됩니다.
- 이어서 자동으로 수집된 공연장 정보가 나옵니다.
- 마지막으로 자동으로 수집된 아티스트 공연이 정렬됩니다.
- 변경 사항은 운영에 배포되어 정상 동작이 확인되었습니다.
