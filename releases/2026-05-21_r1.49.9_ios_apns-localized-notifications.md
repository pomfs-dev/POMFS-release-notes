# r1.49.9 - iOS

Date: 2026-05-21
Component: iOS
Status: deployed

## Summary
iPhone 푸시 알림 수신 경로를 안정화하고, 알림 문구가 수신자의 언어 설정 또는 국가 기준으로 표시되도록 개선했습니다.

## Changes
- iOS 앱의 native APNs 등록 흐름을 웹과 백엔드 알림 경로에 연결했습니다.
- DM, 이벤트 채팅, 팔로우 등 앱 알림이 iPhone native push로도 전달되도록 개선했습니다.
- 사용자가 선호 언어를 설정한 경우 해당 언어를 우선 사용하고, 없으면 국가 기준으로 알림 언어를 선택합니다.
- 한국어, 영어, 스페인어, 태국어, 프랑스어 알림 문구를 지원하며, 지원되지 않는 국가는 영어로 표시됩니다.

## User Impact
- iPhone에서 채팅뿐 아니라 팔로우 등 일반 앱 알림도 native push로 받을 수 있습니다.
- 한국 사용자는 팔로우 알림 등에서 한국어 문구를 받을 수 있습니다.

## Verification
- Web 및 backend production build를 확인했습니다.
- Production backend 배포와 health check를 확인했습니다.
