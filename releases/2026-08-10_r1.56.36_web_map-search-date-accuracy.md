# r1.56.36 - Web

Date: 2026-08-10
Component: Web
Status: deployed

## Summary
지도와 검색에서 공연 수와 '오늘' 기준이 정확하게 표시되도록 수정했습니다.

## Changes
- 지도에서 일부 공연이 표시되지 않거나 공연 수가 실제보다 적게 나오던 문제, '오늘' 표시가 지도 위 표시에 반영되지 않던 문제를 수정했습니다.
- 지도에 많은 공연장이 몰려 요약해서 보여줄 때는 목록 화면에 요약 상태임을 안내합니다.
- '오늘'과 '다가오는 공연' 기준을 사용 중인 기기의 날짜에 맞춰, 자정 이후 이른 시간에 지난 공연이 계속 보이던 문제를 해결했습니다.
- 어두운 화면 설정에서도 지도가 어두운 테마로 표시되며, 언어를 바꾼 뒤에도 지도 글자가 이전 언어로 남던 문제와 공연장 상세가 잠시 빈 화면으로 보이던 문제를 수정했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
