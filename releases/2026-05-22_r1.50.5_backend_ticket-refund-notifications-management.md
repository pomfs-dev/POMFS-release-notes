# r1.50.5 - Backend

Date: 2026-05-22
Released at: 2026-05-22 22:46 KST
Component: Backend
Status: deployed

## Summary
티켓 환불 완료 후 안내 메일과 공연 관리 화면의 환불 상태 표시가 더 정확해지도록 보강했습니다.

## Changes
- 티켓 환불 완료 시 구매자에게 환불 완료 메일을 보내는 흐름을 보강했습니다.
- 티켓 환불 완료 시 운영자에게도 환불 알림 메일이 발송되도록 추가했습니다.
- 공연 생성자가 보는 티켓 관리 화면에서 결제 서버의 최신 환불 상태를 우선 반영하도록 개선했습니다.
- 환불 완료 또는 부분 환불 상태인 주문과 티켓이 사용 가능으로 표시되지 않도록 상태 매핑을 정리했습니다.
- 환불 완료 알림을 공연 생성자에게 전달할 수 있도록 알림 payload를 보강했습니다.

## Known Issues
- 이미 열린 앱 화면은 이전 캐시를 볼 수 있으므로 화면을 새로 열어야 최신 환불 상태가 보일 수 있습니다.
