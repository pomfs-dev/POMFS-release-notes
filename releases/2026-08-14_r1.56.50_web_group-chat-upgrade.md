# r1.56.50 - Web

Date: 2026-08-14
Component: Web
Status: deployed

## Summary
활동 단체 채팅방에 멤버 확인·초대·공유·사진 전송 기능이 더해지고 채팅 사용성이 개선되었습니다.

## Changes
- 단체 채팅방에서 멤버 목록과 프로필 카드를 볼 수 있고, 서로 팔로우한 이용자를 초대하거나 채팅방을 링크로 공유할 수 있으며, 사진도 첨부해 보낼 수 있습니다.
- 채팅방에 새 메시지가 오면 멤버 모두에게 알림이 전달되며, 같은 이름의 모임 채팅방이 중복으로 만들어지지 않습니다.
- 채팅방에 들어갈 때 최신 메시지가 화면에 바로 보이도록 했고, 접속 중 인원이 실제보다 적게 표시되던 문제와 모임을 만들 때 키보드가 올라오면 화면이 깨지던 문제를 수정했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
