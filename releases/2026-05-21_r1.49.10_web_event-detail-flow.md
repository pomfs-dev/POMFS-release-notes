# r1.49.10 - Web

Date: 2026-05-21
Released at: 2026-05-21 03:15 KST
Component: Web
Status: deployed

## Summary
공연 상세, 좋아요, 티켓/게스트리스트, 공유 흐름의 안정성을 개선했습니다.

## Changes
- 좋아요한 아티스트 등록 공연이 Likes 화면에서 올바르게 표시되고, 눌렀을 때 공연 상세가 열리도록 개선했습니다.
- 공연 상세에서 티켓 이름, 가격, 잔여 수량, 인당 최대 수량이 표시되도록 개선했습니다.
- 공연을 만든 계정에서는 티켓 구매/게스트리스트 신청 대신 관리 화면으로 이동하도록 정리했습니다.
- Shows 화면에서 본인이 만든 공연을 열어도 구매/신청 화면으로 잘못 진입하지 않도록 개선했습니다.
- 공연 공유 버튼이 iPhone/WebView와 브라우저에서 더 안정적으로 동작하도록 공유 및 복사 fallback을 추가했습니다.
- 새 배포가 있을 때 업데이트 안내가 더 정확히 감지되도록 개선했습니다.
