# r1.56.111 - Web

Date: 2026-09-15
Component: Web
Status: deployed

## Summary
아티스트 프로필 화면에 갤러리, 링크, 공연 이력, 고유 주소 기능을 추가했습니다.

## Changes
- 프로필에 여러 장의 커버 사진을 등록하고, 갤러리를 그리드와 전체화면으로 볼 수 있게 했습니다.
- 프로필마다 고유한 주소를 만들 수 있도록 했고, 이전 주소로 접속해도 자동으로 연결되도록 했습니다.
- 아티스트 링크와 지난·다음 공연 이력을 보여주는 탭을 새로 추가했습니다.
- 참석, 좋아요, 구독 등 프로필 통계 표시를 더 명확하게 정리했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
