# r1.50.22 - Backend

Date: 2026-06-01
Released at: 2026-06-01 22:26 KST
Component: Backend
Status: deployed

## Summary
관리자 패널에서 회원 삭제가 더 안정적으로 완료되도록 서버 삭제 흐름을 보강했습니다.

## Changes
- 관리자 회원 삭제 과정에서 댓글, 공연, 정산, 등급, 신청 정보처럼 연결된 데이터를 더 일관된 순서로 정리하도록 보강했습니다.
- 삭제 처리 전체를 하나의 안전한 서버 작업으로 묶어 중간 실패 시 일부 데이터만 남는 상황을 방지했습니다.
- 새로운 연결 데이터가 추가되어도 마지막 회원 삭제 단계에서 반복 오류가 나지 않도록 보조 정리 단계를 추가했습니다.
- 운영 배포 후 API 상태와 실제 삭제 경로의 데이터 정리 가능 여부를 확인했습니다.
