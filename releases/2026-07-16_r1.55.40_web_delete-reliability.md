# r1.55.40 - Web

Date: 2026-07-16
Component: Web
Status: deployed

## Summary
구독자나 판매 이력이 있는 공연·공연장, 피드 글을 삭제할 때 오류로 실패하던 문제를 수정하고, 삭제할 수 없는 경우 이유를 명확히 안내하도록 개선했습니다.

## Changes
- 구독자나 티켓 판매 이력이 있는 공연을 삭제하려 할 때 오류가 발생하던 문제를 수정했습니다.
- 공연장 삭제 시 연결된 공연 등 관련 정보가 남아 있으면 삭제가 어려운 이유를 명확히 안내하도록 개선했습니다.
- 피드 글을 삭제할 때 좋아요와 댓글 등 연결된 정보가 함께 정리되지 않던 문제를 수정했습니다.
- 삭제 전에 관련 정보를 먼저 정리하도록 하여 삭제 과정이 안정적으로 완료되도록 개선했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
