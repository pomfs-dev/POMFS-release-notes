# r1.52.9 - Operations

Date: 2026-06-06
Released at: 2026-06-06 15:10 KST
Component: Operations
Status: deployed

## Summary
매일 자동으로 수집된 공연 중 발행 기준을 충족하는 공연이 자동으로 앱에 올라가도록 개선했습니다.

## Changes
- 매일 수집된 공연 정보 가운데 발행 기준을 충족하는 항목이 별도의 수동 단계 없이 자동으로 앱에 발행되도록 했습니다.
- 그동안 직접 진행하던 발행 단계를 자동화하여, 새로운 공연이 더 빠르게 앱에 노출되도록 했습니다.
- 이미 발행된 공연은 다시 올라가지 않도록 처리해, 같은 공연이 중복으로 노출되지 않도록 했습니다.
- 안정적인 운영을 위해 자동 발행 동작을 안전하게 관리할 수 있도록 했습니다.
- 위 변경 사항을 운영 환경에 배포하고 정상 동작을 확인했습니다.
