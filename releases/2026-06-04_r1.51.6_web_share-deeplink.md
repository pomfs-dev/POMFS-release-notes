# r1.51.6 - Web

Date: 2026-06-04
Released at: 2026-06-04 00:30 KST
Component: Web
Status: deployed

## Summary
공유한 아티스트·공연장·게시물 링크가 앱의 알맞은 화면으로 더 정확하게 열립니다.

## Changes
- 공유 링크를 눌렀을 때 아티스트, 공연장, 게시물 등 콘텐츠 종류에 맞는 화면으로 더 정확하게 연결되도록 개선했습니다.
- 카카오톡 인앱(채팅 안에서 링크를 바로 여는 환경)에서 공유한 콘텐츠가 의도한 화면으로 올바르게 열리도록 개선했습니다.
- 공유받은 사람이 링크를 통해 곧바로 해당 아티스트·공연장·게시물 화면을 볼 수 있어 길을 잃지 않고 콘텐츠에 도달할 수 있습니다.
- 위 변경 사항을 실제 서비스에 배포하고 공유 링크 연결 동작을 확인했습니다.
