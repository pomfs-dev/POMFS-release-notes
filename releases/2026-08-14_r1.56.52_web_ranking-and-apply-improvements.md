# r1.56.52 - Web

Date: 2026-08-14
Component: Web
Status: deployed

## Summary
아티스트·공연장 등록 신청 과정의 안내가 자세해지고 랭킹 화면 이용이 편해졌습니다.

## Changes
- 아티스트·공연장 등록을 신청할 때 SNS 계정이 확인되지 않거나 이미 사용 중이면 해당 입력칸 옆에서 바로 안내를 볼 수 있고, 자기소개가 20자 미만인 경우에도 이유가 표시됩니다.
- 판매자 본인 확인이 반려되면 반려 사유를 확인하고 즉시 다시 신청할 수 있습니다.
- 랭킹 화면에서 티어 탭이 항상 유지되고 목록을 이어서 안정적으로 볼 수 있으며, 인스타그램 링크를 누르면 인스타그램 앱으로 바로 열립니다.
- 사이드바에서 아티스트·공연장 대시보드로 바로 이동할 수 있습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
