# r1.56.77 - Web

Date: 2026-08-31
Component: Web
Status: deployed

## Summary
홈 화면에서 바로 서비스 스토어를 둘러볼 수 있도록 하고, 서비스 화면의 표시 문제를 함께 수정했습니다.

## Changes
- 홈 화면에 서비스 스토어 섹션을 새로 노출하고, 다른 섹션과 동일한 간격으로 정돈했습니다.
- 서비스 상세 화면이 열리지 않고 오류로 중단되던 문제를 수정했습니다.
- 한국어 이외의 언어에서 서비스 이름과 설명이 한국어로 표시되던 문제를 수정했습니다.
- 서비스 카드의 대표 이미지 크기와 여백이 화면을 과도하게 차지하던 문제를 정리했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
