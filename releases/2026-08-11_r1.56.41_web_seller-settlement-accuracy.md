# r1.56.41 - Web

Date: 2026-08-11
Component: Web
Status: deployed

## Summary
판매자 정산 화면의 수수료 표시와 계산 기준을 바로잡고 정산 절차를 정비했습니다.

## Changes
- 정산 화면에 수수료가 정액 기준으로 표시되어 실제 공제 금액을 명확히 확인할 수 있습니다.
- 소액 티켓에서 수수료가 판매 금액보다 크게 계산될 수 있던 문제를 수정했습니다.
- 티켓 판매 대금은 공연 종료 이후에 지급되도록 정산 기준을 정비했습니다.
- 판매자 인증 심사 결과가 별도 요청 없이 자동으로 반영됩니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
