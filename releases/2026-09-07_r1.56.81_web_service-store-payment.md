# r1.56.81 - Web

Date: 2026-09-07
Component: Web
Status: deployed

## Summary
서비스 스토어에서 수락된 신청을 앱 안에서 바로 결제하고 결제 상태를 확인할 수 있습니다.

## Changes
- 수락된 서비스 신청에 '결제하기' 버튼이 추가되어 결제창에서 바로 결제를 진행할 수 있습니다.
- 결제가 끝난 신청은 목록 배지와 상세 화면에 '결제 완료'로 표시됩니다.
- 신청 화면에서 PC 달력이 열리지 않거나 글자 수 제한 안내가 없던 문제, 내 신청 목록에 금액이 잘못 표시되거나 화면이 멈추던 문제, 상품명이 영어로만 나오던 문제를 고쳤습니다.
- 서비스 스토어는 현재 한국 이용자에게만 제공됩니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
