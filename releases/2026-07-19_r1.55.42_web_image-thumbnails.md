# r1.55.42 - Web

Date: 2026-07-19
Component: Web
Status: deployed

## Summary
업로드된 이미지에 경량 썸네일을 자동 생성하고 목록·지도·홈 화면에 적용하여 앱 전반의 이미지 로딩 속도를 크게 개선했습니다.

## Changes
- 이미지를 업로드하면 가벼운 썸네일이 자동으로 함께 만들어지도록 개선했습니다.
- 공연 목록과 카드, 공연 지도 마커에서 원본 대신 썸네일을 사용해 화면이 더 빠르게 열리도록 했습니다.
- Today 화면의 캐러셀 이미지는 화면에 보일 때 불러오도록 하여 첫 화면 표시 속도를 높였습니다.
- 지도를 넓게 볼 때 마커 정보를 잠시 기억해 두어 지도 탐색이 더 부드러워졌습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.

## Known Issues
- 이번 업데이트 이전에 업로드된 일부 이미지는 썸네일이 순차적으로 생성되며, 그동안 기존 방식으로 표시될 수 있습니다.
