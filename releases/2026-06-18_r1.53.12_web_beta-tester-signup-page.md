# r1.53.12 - Web

Date: 2026-06-18
Component: Web
Status: deployed

## Summary
안드로이드 비공개 베타 테스터를 모집하는 신청 페이지를 추가했습니다.

## Changes
- 이름·연락처·이메일을 입력해 베타 테스트를 신청할 수 있는 페이지를 추가했습니다(/beta).
- 안드로이드 기기에서만 참여 가능하다는 점을 명확히 안내합니다.
- 비공개 테스트는 Google 계정으로만 참여 가능하여, Google(Gmail) 계정 이메일만 신청을 받습니다.
- 신청이 접수되면 운영진에게 알림이 전달됩니다.
- 변경 사항이 배포되었습니다.
