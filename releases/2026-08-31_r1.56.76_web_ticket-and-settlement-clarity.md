# r1.56.76 - Web

Date: 2026-08-31
Component: Web
Status: deployed

## Summary
티켓과 정산 화면의 날짜·수수료·지급 안내를 실제 기준에 맞게 정정했습니다.

## Changes
- 티켓 보관함과 티켓 확인 화면의 공연일에 연도를 함께 표시해 지난 연도 티켓을 구분할 수 있도록 했습니다.
- 정산 수수료 안내를 '주문 1건당' 기준으로 정정하고, 지원하는 모든 언어에 동일하게 적용했습니다.
- 자동 지급이 아직 준비 중인 경우 '자동 지급된다'고 안내하던 문구를 준비 중 안내로 바로잡았습니다.
- 주문 번호 라벨과 안내 문구 표기를 정리했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
