# r1.52.10 - Data Pipeline

Date: 2026-06-06
Released at: 2026-06-06 23:00 KST
Component: Data Pipeline
Status: deployed

## Summary
AI로 수집된 공연이 지도에 올바른 위치로 표시되도록 위치 정보를 보강하고, 매일 진행되는 데이터 정리 과정을 더 빠르고 안정적으로 개선했습니다.

## Changes
- AI가 수집한 공연이 위치 정보 없이 등록돼 공연 지도에서 누락되거나 엉뚱한 지역에 표시되던 문제를 해결했습니다.
- 공연을 수집하는 시점에 위치 정보를 함께 보강해, 지도에서 올바른 위치에 표시되도록 개선했습니다.
- 기존에 위치 정보가 없던 공연들도 다시 점검해 위치 정보를 채워 넣었습니다.
- 매일 자동으로 진행되는 공연·공연장 정보 수집과 정리 과정을 더 빠르고 안정적으로 처리하도록 개선했습니다.
- 위 변경 사항을 운영 환경에 배포하고 정상 동작을 확인했습니다.

## Known Issues
- 원본에 위치 정보가 전혀 없는 일부 공연은 지도에 표시되지 않을 수 있습니다.
