## Summary
Today와 Shows에서 필요한 위치 기능을 다시 사용할 수 있도록 하면서 결제 화면에서는 위치 사용을 막았습니다.

## Changes
- Today의 내 주변 공연 필터를 버튼 클릭 기반으로 복구했습니다.
- Shows 지도에서 지도 화면이 보이는 동안 현재 위치 마커가 유지되도록 복구했습니다.
- Shows에서 리스트로 전환하거나 다른 화면으로 이동하면 위치 감시가 중단되도록 범위를 제한했습니다.
- 결제와 티켓 화면에서는 위치 API가 동작하지 않도록 유지했습니다.
- 설치된 앱이 새 웹 번들을 감지할 수 있도록 업데이트 감지 버전을 갱신했습니다.
