# r1.56.127 - Web

Date: 2026-09-27
Component: Web
Status: deployed

## Summary
프로젝트 모집 공고를 수정하고 저장할 때 내용이 제대로 반영되도록 개선했습니다.

## Changes
- 업계 목록의 상세 화면에서 내가 올린 글의 수정·삭제 메뉴가 표시되도록 개선했습니다.
- 공고 수정 화면의 제목 중복 표시, 저장 버튼이 눌리지 않던 현상, 번역되지 않은 문구를 바로잡았습니다.
- 공고를 수정해 저장하면 포지션, 마감일, 모집 인원, 이미지가 반영되지 않던 문제를 해결했습니다.
- 새 공고를 작성하거나 기존 공고를 수정할 때 선택한 장르가 저장되도록 했으며, 내 프로젝트 목록에 장르 이름이 표시됩니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
