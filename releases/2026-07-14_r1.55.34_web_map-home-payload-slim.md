# r1.55.34 - Web

Date: 2026-07-14
Component: Web
Status: deployed

## Summary
공연 지도와 홈 화면이 불러오는 데이터 양을 대폭 줄여 화면이 훨씬 빠르게 열리도록 개선했습니다.

## Changes
- 공연 지도를 넓게 축소해 볼 때 꼭 필요한 마커와 공연 수 정보만 불러오도록 개선하여 지도가 훨씬 빠르게 표시됩니다.
- 홈 화면에서는 게시글 미리보기만 간략히 보여주고, 상세 내용은 열어볼 때 전체를 불러오도록 하여 첫 화면이 가벼워졌습니다.
- Today의 AI 수집 공연은 표시 기간에 해당하는 공연만 불러오도록 하여 홈 화면 로딩을 크게 줄였습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
