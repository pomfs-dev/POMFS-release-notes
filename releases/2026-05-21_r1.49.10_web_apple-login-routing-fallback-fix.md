# r1.49.10 - Web

Date: 2026-05-21
Component: Web
Status: not-deployed

## Summary
Apple 로그인 버튼이 잘못된 로그인 경로로 이동하던 문제를 수정했습니다.

## Changes
- Apple 로그인 시작 경로를 실제 Apple 로그인 흐름으로 연결했습니다.
- Apple 로그인 완료 후 세션을 저장하고 커뮤니티 첫 화면으로 돌아오도록 개선했습니다.
- 기존 Google 로그인 세션이 남아 있을 때 뒤로가기 후 자동 로그인되는 동작과 Apple 로그인 오류를 분리해 처리했습니다.

## Known Issues
- Apple Developer 설정에 커뮤니티 도메인의 Apple 로그인 callback URL 등록이 필요합니다.
- 이미 로그인된 브라우저에서는 기존 세션에 따라 Today 화면으로 바로 이동할 수 있습니다.
