# r1.56.45 - Web

Date: 2026-08-11
Component: Web
Status: deployed

## Summary
공유 링크로 게시글이 열리지 않던 문제와 여러 화면 표시 오류를 수정했습니다.

## Changes
- 공유받은 링크로 게시글을 열 때 해당 글이 열리지 않고 다른 화면으로 이동하던 문제를 수정했습니다.
- 모바일에서 서비스 카드의 가격이 잘려 보이던 문제와 게시글 본문이 카드 밖으로 넘치던 문제를 수정했습니다.
- 예정 공연 카드의 날짜 표시, 공연장 상세 화면의 이미지 높이, 영어 화면의 단수·복수 표기를 다듬었습니다.
- 앱 업데이트 직후 화면이 일시적으로 열리지 않는 경우 자동으로 복구되도록 개선했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
