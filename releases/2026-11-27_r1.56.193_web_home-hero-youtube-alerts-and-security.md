# r1.56.193 - Web

Date: 2026-11-27
Component: Web
Status: deployed

## Summary
홈 화면의 영상 표시와 새 영상 알림을 정리하고 보안을 강화했습니다.

## Changes
- 삭제된 유튜브 영상이 홈 화면 상단 영상 영역에 계속 노출되던 문제를 수정했습니다.
- 표시할 영상이 없을 때는 홈 화면 상단 영상 영역이 빈 공간으로 보이지 않도록 개선했습니다.
- 새 영상 알림은 공개된 일반 영상에 대해서만 보내고, 쇼츠는 알림에서 제외하도록 변경했습니다.
- 서비스 전반의 보안을 강화했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
