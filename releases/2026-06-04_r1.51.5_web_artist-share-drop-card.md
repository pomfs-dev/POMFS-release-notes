# r1.51.5 - Web

Date: 2026-06-04
Released at: 2026-06-04 08:21 KST
Component: Web
Status: deployed

## Summary
아티스트 프로필 공유 링크가 예시 데이터 대신 실제 정보가 담긴 "드롭 명함" 화면으로 곧바로 연결됩니다.

## Changes
- 아티스트 프로필 공유 링크를 열면 예시 데이터 화면이 아니라 실제 데이터 기반의 "드롭 명함" 화면으로 자동 이동합니다.
- 도착한 드롭 명함 화면에서 팔로우, 메시지, 공유 버튼을 바로 사용할 수 있도록 활성화했습니다.
- 화면에 표시되는 배지 문구를 정리해 더 깔끔하게 보이도록 다듬었습니다.
- 프로필 화면의 팔로잉, 게시물 등 요약 수치를 실제 값으로 정확하게 표시합니다.
- 변경 사항을 운영 환경에 배포하고 정상 동작을 확인했습니다.
