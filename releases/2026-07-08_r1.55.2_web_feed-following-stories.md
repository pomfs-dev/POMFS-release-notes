# r1.55.2 - Web

Date: 2026-07-08
Component: Web
Status: deployed

## Summary
피드 상단에 팔로우한 프로필과 추천 아티스트를 가로로 보여주는 스토리 레일을 추가하고, 새 글이 올라온 프로필은 링으로 눈에 띄게 표시합니다.

## Changes
- 피드 장르 선택 아래에 팔로우 프로필·추천 아티스트를 가로로 넘겨 보는 스토리 레일을 추가했습니다.
- 안 본 새 글이 있는 프로필은 아바타에 링이 켜져 한눈에 알 수 있습니다.
- 아바타를 누르면 프로필로 이동하고, 확인한 새 글 표시는 자동으로 사라집니다.
- 레일에서 바로 팔로우하거나 추천 프로필을 숨길 수 있습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
