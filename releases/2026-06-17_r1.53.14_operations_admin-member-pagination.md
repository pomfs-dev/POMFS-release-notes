# r1.53.14 - Operations

Date: 2026-06-17
Component: Operations
Status: deployed

## Summary
관리 도구의 회원 목록에서 전체 회원을 페이지로 나눠 보고, 등급별로 빠르게 필터링할 수 있도록 개선했습니다.

## Changes
- 기존에는 회원 목록이 일부만 보여 전체 회원을 확인하기 어려웠는데, 이전·다음 페이지 이동을 추가해 전체 회원을 볼 수 있습니다.
- 등급(전체·리스너·아티스트·공연장·스태프) 필터를 인원수와 함께 추가해, 원하는 등급의 회원만 빠르게 볼 수 있습니다.
- 회원 검색, 등급 필터, 페이지 이동을 함께 사용할 수 있습니다.
- 운영 배포 후 정상 동작을 확인했습니다.

## Known Issues
- 마지막 페이지에서 회원을 삭제하면 해당 페이지가 잠시 비어 보일 수 있으며, 이전 페이지로 이동하면 정상적으로 표시됩니다.
