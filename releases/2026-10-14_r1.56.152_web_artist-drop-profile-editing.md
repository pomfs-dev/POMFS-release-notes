# r1.56.152 - Web

Date: 2026-10-14
Component: Web
Status: deployed

## Summary
아티스트 드롭과 프로필에서 직접 수정할 수 있는 항목이 늘어났습니다.

## Changes
- 아티스트 드롭 편집 화면에서 서브장르와 대표 계정을 수정할 수 있습니다.
- 드롭 편집 화면에서 틱톡 아이디, 프로필 사진, 공개 주소, 여러 장의 커버 이미지를 수정할 수 있습니다.
- 프로필에서도 신청서를 다시 제출하지 않고 틱톡 아이디를 수정할 수 있습니다.
- 가입 직후 온보딩과 프로필 설정에서 사진을 자르기 전의 원본이 보관되어, 이후 사진을 다시 편집하기 편해졌습니다.
- 대표 계정을 켜고 저장할 때 세부 역할이 사라지던 문제를 바로잡았습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
