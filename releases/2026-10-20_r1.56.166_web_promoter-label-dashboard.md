# r1.56.166 - Web

Date: 2026-10-20
Component: Web
Status: deployed

## Summary
프로모터와 레이블 계정의 대시보드 이동과 공개 카드 표시를 개선했습니다.

## Changes
- 프로모터와 레이블 계정의 대시보드가 공연 관리 화면으로 올바르게 연결됩니다.
- 프로모터·레이블의 공개 카드에는 꼭 필요한 정보만 간결하게 표시됩니다.
- 프로모터·레이블 계정에는 해당되지 않는 프레스킷, 보도사진, 섭외 화면이 열리지 않도록 정리했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
