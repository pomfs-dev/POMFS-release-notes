# r1.56.119 - Web

Date: 2026-09-15
Component: Web
Status: deployed

## Summary
공연 등록과 관리 기능을 더 정교하게 다듬었습니다.

## Changes
- 등록한 공연을 게시·숨김·삭제 상태로 구분해 관리할 수 있도록 목록을 개편했습니다.
- 공연 등록 시 장르를 하나만 선택하도록 해 정보가 덮어써지는 문제를 방지했습니다.
- 이미 지난 날짜로 공연을 등록하거나 날짜를 되돌리는 것을 제한했습니다.
- 일부 공연장의 공연에서 비어 있던 장르 정보를 채워 넣었습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
