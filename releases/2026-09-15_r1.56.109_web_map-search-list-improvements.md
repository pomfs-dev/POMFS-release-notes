Date: 2026-09-15
Component: Web
Status: deployed

## Summary
지도와 공연 목록, 검색 결과 표시 방식을 개선했습니다.

## Changes
- 지도와 공연 목록에서 특정 조건일 때 화면이 정상적으로 표시되지 않던 문제를 수정했습니다.
- 검색 결과에 공연장이 직접 등록한 공연도 포함되도록 개선했습니다.
- 검색어에 오타가 있어도 더 정확한 결과를 찾을 수 있도록 개선했습니다.
- 일시적으로 서비스 접속이 원활하지 않던 문제를 개선했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
