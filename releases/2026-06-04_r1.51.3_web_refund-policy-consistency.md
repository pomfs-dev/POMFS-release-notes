# r1.51.3 - Web

Date: 2026-06-04
Released at: 2026-06-04 12:00 KST
Component: Web
Status: deployed

## Summary
공연별 환불 정책이 구매 화면, 환불 화면, 실제 환불 처리에 일관되게 표시·적용되도록 정리했습니다.

## Changes
- 공연마다 정해진 환불 가능 기간과 수수료가 구매 화면에 정확히 표시됩니다.
- 환불 화면에 안내되는 내용이 실제 환불 처리 결과와 일치하도록 맞췄습니다.
- 환불이 완료되면 구매자에게 환불 안내 메일이 발송됩니다.
- 환불이 완료되면 주최자에게도 안내 메일이 발송됩니다.
- 화면에 보이는 환불 안내와 실제 처리 금액이 어긋나지 않도록 전반적으로 정합성을 정리했습니다.
- 배포 후 실제 결제·환불 흐름으로 정상 동작을 확인했습니다.
