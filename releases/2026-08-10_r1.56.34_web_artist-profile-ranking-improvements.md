# r1.56.34 - Web

Date: 2026-08-10
Component: Web
Status: deployed

## Summary
아티스트 프로필과 랭킹이 실제 활동 내용을 정확하게 보여주도록 개선했습니다.

## Changes
- 아티스트 프로필의 갤러리와 소개 자료가 예시 내용이 아닌 실제 등록 자료로 표시되며, 게시물 수와 팔로잉 수가 항상 0으로 보이던 문제를 수정했습니다.
- 아티스트 카드에 저장한 내용과 화면에 보이는 내용이 서로 어긋나던 문제를 수정하고, 소개가 비어 있을 때의 표시 순서를 정리했습니다.
- 아티스트 랭킹에서 본인이 누른 좋아요는 집계에서 제외하고, 지난 특정 시점으로 고정돼 있던 기준 안내를 실시간 기준으로 바꿨습니다. 인기 아티스트 소개 문구도 실제 순위 기준에 맞게 정정했습니다.
- 아티스트 목록에서 줄 전체를 눌러 상세 카드를 열 수 있게 하고, 등록 신청 시 소셜 계정과 링크의 중복 여부 및 실제 존재 여부를 확인하도록 개선했으며 필수 입력 항목의 순서를 바로잡았습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
