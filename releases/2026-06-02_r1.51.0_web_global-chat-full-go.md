# r1.51.0 - Web

Date: 2026-06-02
Released at: 2026-06-02 19:44 KST
Component: Web
Status: approved

## Summary
MiSFY 커뮤니티에서 메시지와 이벤트 채팅을 더 안정적으로 사용할 수 있도록 글로벌 채팅 기반을 정식 승인했습니다.

## Changes
- 메시지와 이벤트 채팅을 위한 서버 처리와 읽음/알림 흐름을 더 안정적으로 정리했습니다.
- 채팅 링크를 열었을 때 웹과 iOS 앱이 메시지 목록이나 해당 대화 화면으로 더 정확하게 이동하도록 개선했습니다.
- iOS 앱에서 로그인 후 알림 허용 안내가 표시되고, 허용 시 기기 알림 설정과 앱 알림 등록이 이어지도록 보강했습니다.
- iOS 푸시 알림을 눌렀을 때 메시지 목록에만 머무르지 않고 관련 대화로 이동하도록 개선했습니다.
- iOS 앱의 실행 화면, 앱 아이콘, 표시 이름을 MiSFY 브랜드 기준에 맞춰 정리했습니다.
- 운영 배포와 실기기 테스트를 통해 웹, iOS 앱, 알림, 딥링크, 기본 채팅 송수신 흐름을 확인했습니다.

## Known Issues
- iOS 네이티브 앱 변경은 사용자가 새 앱 빌드를 설치한 뒤 적용됩니다.
