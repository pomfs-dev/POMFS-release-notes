Date: 2026-05-21

Component: Web
Status: deployed

## Summary
공연 수정 후 관리 목록의 가격 표시와 뒤로가기 흐름을 개선했습니다.

## Changes
- 공연 수정 완료 후 내 공연 관리 목록이 최신 정보로 다시 불러와지도록 개선했습니다.
- 티켓 금액을 변경한 뒤 관리 목록에 이전 금액이 남아 보이는 문제를 수정했습니다.
- 공연 수정 완료 후 관리 목록에서 뒤로가기를 눌렀을 때 수정 화면으로 돌아가지 않도록 흐름을 정리했습니다.
- 더보기 메뉴에서 공연 등록/관리로 들어온 경우 뒤로가기 시 더보기 메뉴로 자연스럽게 돌아가도록 개선했습니다.
