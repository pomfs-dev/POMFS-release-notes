# r1.56.42 - Web

Date: 2026-08-11
Component: Web
Status: deployed

## Summary
아티스트를 티어별로 둘러볼 수 있는 목록과 프로필 포스트 관리 기능을 추가했습니다.

## Changes
- 아티스트 화면에 MiSFY 아티스트·대륙·전국·로컬 네 가지 티어별 목록이 추가되었습니다.
- 아티스트 프로필에 포스트 탭이 추가되었고, 작성한 포스트와 공연 이력을 직접 수정하거나 삭제할 수 있습니다.
- 아티스트 지원 시 이미 등록된 SNS 계정을 입력하면 중복 여부를 안내해 드립니다.
- 프로필 설정의 'Beta 무료' 표시를 정리해 등급 안내를 더 명확하게 했습니다.
- 위 변경 사항을 운영 환경에 반영했습니다.
