# r1.50.15 - Web

Date: 2026-05-28
Released at: 2026-05-28 07:31 KST
Component: Web
Status: deployed

## Summary
프로필 설정의 정산 계좌 등록 이동과 계정 삭제 확인 흐름을 복구했습니다.

## Changes
- 플랜 및 등급 화면의 정산 계좌 등록 버튼이 정산 현황이 아닌 정산 계좌 등록 화면으로 이동하도록 수정했습니다.
- 정산 계좌 등록 전용 화면을 프로덕션 라우트에 연결했습니다.
- 프로필 설정의 계정 삭제 확인 버튼이 인증된 삭제 요청을 보내고 처리 중 상태를 표시하도록 수정했습니다.
- 커뮤니티 웹 프로덕션 서비스를 새 버전으로 롤링 배포했습니다.

## Known Issues
- 이미 열린 브라우저 탭은 새 버전 알림 또는 새로고침 후 최신 화면으로 전환될 수 있습니다.
